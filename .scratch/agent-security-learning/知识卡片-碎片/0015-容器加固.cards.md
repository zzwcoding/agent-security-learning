# 0015 容器加固 —— 知识卡片

来源:`issues/07-route1-execution/lessons/0015-容器加固.md`

### 容器加固六项(Docker Container Hardening)

**是什么**:不改 Agent 一行逻辑,用 Docker 机制给运行环境上枷锁。六项:`USER agent`(非 root)、`--read-only`(根 fs 只读)、`--tmpfs /tmp:rw,noexec,nosuid,size=64m`(唯一可写口)、`--cap-drop ALL` + `--security-opt no-new-privileges`(提权封死)、`--memory 3g --cpus 2`(资源封顶)、网络保留(LLM API 硬依赖,egress 缺口由此留下)。
**解决什么问题**:失效假设是"护栏全崩、注入得手"——此时目标从防住攻击变成压缩爆炸半径:写文件只有 64MB 内存盘、提权无路、拖不垮宿主、`--rm` 退出即焚。
**我们的办法**:挂载点 = `scripts/docker-run.sh` + `Dockerfile`;收益最大的两项是只读 fs 和非 root——攻击者最常用的落地动作(写文件、改配置、植持久化)全部归零。账单要记明:镜像 4.96GB、启动多 5 秒;挂卷文件须 `chmod 666`,否则非 root 容器用户写不动记忆。

### 数据边界 vs 进程边界(Data Boundary vs Process Boundary)

**是什么**:两类防线回答不同问题。三层护栏(输入/工具返回/输出)是**数据边界**——拦毒文本、拦密钥;容器加固是**进程边界**——假设数据边界全破,限制攻陷后的可用权限。
**解决什么问题**:缺一不可:护栏减少"沦陷概率",加固减少"沦陷损失",风险 = 两者乘积;只堆护栏,一旦被绕就回到阶段 9 的裸奔态。
**我们的办法**:路线 1 先建数据边界(阶段 12–14),再建进程边界(本阶段);实测战利品 B(`run_command` 建标记文件)在加固容器里直接失效,`touch /app/PWNED` 报 `Read-only file system`。

### 出站外泄缺口(Egress Exfiltration Gap)

**是什么**:攻击者 = 已注入得手、劫持 Agent 工具的人;毒不需要"进",已经读到的东西(密钥、文件)需要"出"——容器网络保留,egress 不过滤,外泄通道敞开。
**怎么得手**:同容器里 `urllib` 访问 `api.minimaxi.com` 拿到真实 HTTP 404——网络是通的;写不了文件,但能把读到的密钥 POST 出去。文件系统锁得再死,网络这扇门开着,容器就漏风。
**我们的对策**:未防,如实记账为已知缺口,移交路线 2;对照 codex `read-only` 档默认连网都不给,本项目因 LLM API 与 fetch 硬依赖选择了开——这是权衡,不是遗漏。

### codex sandbox_mode 三档(codex CLI Sandbox Modes)

**是什么**:OpenAI codex CLI 的沙盒分档:`read-only`(默认,写全无、网默认关)、`workspace-write`(仅 cwd+/tmp 可写、网默认关可显式开)、`danger-full-access`(全开放)。信源:backgrind 沙盒模式解析 + codex 仓库协议定义。
**解决什么问题**:给"Agent 该有多大权限"提供业界参照系——本项目挂卷 workspace + tmpfs 对应 `workspace-write`,但网络选了开(比 codex 默认松);阶段 9 裸奔态 = `danger-full-access`。
**我们的办法**:两个可借鉴设计:① `sandbox_mode` 与 `approval_policy`(人审)是**两个独立维度**,不耦合;② codex 沙盒用 OS 原生机制(macOS Seatbelt / Linux Landlock+seccomp)直接锁 Agent 进程,不依赖容器——路线 2 的 microsandbox 同思路。

### 意图/动作/后果三问(Intent / Action / Effect Evaluation)

**是什么**:评估一层防御先问:它拦的是意图、动作,还是后果?容器加固管的是**效果**——恶意命令在容器里照样"执行",只是效果被只读 fs 吞掉。
**为什么重要**:不问清这一点就会误判防线:容器没拦下 `touch` 的执行(退出码层面命令跑了),但落地动作全部 syscall 级失败;"防住了"到底指哪一层,必须说清才能比较和对账。
**我们怎么用**:同一条 `run_command("touch PWNED")` 跑两世——宿主上退出码 0 文件出现(阶段 9),加固容器里报 Read-only file system(本阶段);差异不在命令是否执行,而在效果是否被环境吞掉。
