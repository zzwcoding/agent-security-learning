## 依赖冲突(本阶段最大坑)

- pyrit 1.0.1 要求 `transformers>=5.0.0rc3`;llm-guard 0.3.16 钉死 `transformers==4.51.3`。
  **同一环境物理不可共存**,uv 解完把 transformers 顶到 5.16.1、tokenizers 0.21.4→0.23.1,torch 2.13.0 未动。
- 处置:实证项目实际用到的两个扫描器在新版下正常——PromptInjection 毒样本 1.00 抓、
  善意中文 0.60(=已知中文盲区,非回归)、Sensitive 抓 PII。llm-guard 的钉死在元数据上
  被违反,靠实证背书,后续装包注意 uv 可能试图"修复"环境。
- `requirements-lock.txt` 未动(惯例:间接依赖锁定随 Docker 阶段补齐)。
- garak 独立 venv(.venv-garak)的原因:它只打 HTTP 面,没必要进 agent 环境冒冲突;
  PyRIT 必须进主 venv 的原因:进程内 PromptTarget 要 import agent。
