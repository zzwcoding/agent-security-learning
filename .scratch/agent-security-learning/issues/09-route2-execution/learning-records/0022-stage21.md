# 0022 阶段 21:microsandbox 安装 + SDK 最小闭环

**学了什么**:microsandbox(macOS 上走 Hypervisor.framework 的真 microVM,libkrun 核心)安装与两种使用形态——CLI `msb run` 和 Python SDK `Sandbox.create()`;核实 SDK 是嵌入式(子进程拉 VM,无守护进程)。

**过程**:
1. `brew install superradcompany/tap/microsandbox` → 0.6.16 一次成功
2. `msb run python -- python -c ...` → 输出 `Linux aarch64`,首次拉 python 镜像耗时几分钟(后台任务完成)
3. `uv pip install --python starter-agent/.venv/bin/python microsandbox` → 0.6.16,与 CLI 同版本
4. 读包内 `_microsandbox.pyi` + `types.py` 核实 API(Rust 原生扩展,无 Python 源码可看):`Sandbox.create(name, image, ephemeral, network, secrets)` / `sb.shell(script)` / `sb.exec(cmd, args)` → `ExecOutput(exit_code, stdout_text, stderr_text)`;网络策略是 `NetworkPolicy`(default_egress=DENY + rules)而非简单的 allowed_hosts 列表——比票 04 研究时(2026-08 月初)的文档进化了,白名单写法要按新版 `Rule.allow(destination=Destination.domain(...))` 来
5. SDK 探针 `/tmp/msb_probe.py` 一把过:Linux 6.12.99 aarch64 / hostname=sandbox 名 / `/Users` 不存在 / curl httpbin 200(默认出网全开),闭环 15 秒

**卡在哪**:没卡。唯一意外:试图 `inspect.getsource()` 看 SDK 实现失败——是 .so 原生扩展,只能看 .pyi 存根和 types.py。

**结论**:beta 风险未爆雷,API 与文档一致(且比研究时更强)。可以进阶段 22 改造 shell_server。探针脚本在 /tmp,未入项目。

**证据**:lesson 0018;`msb --version` = 0.6.16。
