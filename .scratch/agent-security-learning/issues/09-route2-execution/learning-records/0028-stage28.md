**过程**:

**卡在哪**:输入护栏(L4)连拦四次导致端到端验证一度受阻——"用一句话说明你是谁"0.99、"请记住我的联系方式"1.0、"我的邮箱是…"0.98、"随便编一个示例联系方式"0.99,全是误报。绕行:纯算术输入"13800138000 加 1 等于几"通过,模型回复自然含 11 位数字,落库时全部消毒。系统性观察:L4 对"PII/联系方式类话术"系统性误杀——两层防线打架(它拦入口误报,本阶段兜出口漏报),原样记入 record,阈值调优留待攻击验收后统一做。
