# 0022 凭证代理 LLM 路(阶段 26)

## 三问(阶段动机)

**终极目标**:Agent 就算被注入完全劫持,也伤不到宿主机、偷不到真密钥。

路线图:

```
✅ 阶段21-22:执行面进 microVM(shell/fetch)
✅ 阶段23:出网白名单(缺口 1 核销)
✅ 阶段24:Docker vs microVM 边界对比
✅ 阶段25:自修改 agent 复刻(平行窗口进行中)
👈 阶段26:凭证代理 LLM 路(真 key 撤出 Agent 进程)
⬜ 阶段27:凭证代理 fetch 路(占位符替换)
⬜ 阶段28-29:脱敏 + 审计    ⬜ 阶段31:四次攻击验收
```

**这一阶段是干嘛的?** 在 Agent 和 MiniMax 之间塞一个本地小代理:Agent 的请求先到代理,代理把 Authorization 换成真 key 再转发。从此 Agent 进程里只有 `PLACEHOLDER` 占位符,真 key 只活在代理进程。

**什么需求逼的?** 路线 1 反复证明:注入得手后,攻击者能让 Agent 做任何事——dump 环境变量只是其中最便宜的一招。前面所有防线(microVM、白名单、护栏)都管不住一件事:**密钥在攻击面里,就迟早被读走**。唯一可靠的解法是让密钥根本不在场。

**解决了什么麻烦?** "劫持了 Agent"和"拿到了密钥"从此是两件事。阶段 31 的"密钥不可见"攻击,地基就在这里。

## 全链路一览

```
Agent 进程(只有 PLACEHOLDER)                    代理进程(有真 key)
  base_url = 127.0.0.1:5055/v1
  Authorization: Bearer PLACEHOLDER  ──────→  proxy.py 收到
                                              把 authorization 头换成真 key
                                              转发 api.minimaxi.com ──→ MiniMax
  SSE 分块原样回传                 ←──────  响应字节流原样透传 ←──
```

改动极小:Agent 侧只换了三个常量的默认值(config.py),模型、护栏、观测全部无感。

## 跟着数据走:三个请求的命运

1. **占位符直连 MiniMax** → `401`(对照:没有代理,占位符就是废物)
2. **占位符经代理** → 代理把 `Bearer PLACEHOLDER` 换成 `Bearer <真key>` → `200`,拿到补全
3. **Agent 真跑**(`scripts/run-agent.sh`,零 LLM 环境变量裸启动)→ 问"1加1等于几"→ 经代理拿到"1 加 1 等于 **2**";`agent.astream` 的 SSE 流式分块原样透传,体验无感

看代理日志,只有一行元数据:`→ POST /v1/chat/completions ← 200 0.76s 868B`——对话内容和密钥都不在日志里。

## 新技术点:SSE 流式透传

- **名字**:StreamingResponse(FastAPI/Starlette)+ `httpx` 的 `send(stream=True)`/`aiter_raw()`
- **作用**:大模型回复是一块一块到的(SSE,Server-Sent Events)。代理若"读完再转",流式就退化成等待;`aiter_raw()` 把上游字节块原样往下吐,Agent 端的打字机效果不变
- **参数/用法**:`upstream_resp.aiter_raw()` 是异步生成器,`finally` 里必须 `await upstream_resp.aclose()`(不关上游连接=连接池泄漏);逐跳头(host/content-length/authorization)不透传——长度由 httpx 重算,授权由我们注入
- **本项目位置**:`proxy.py` 的 `forward()`;为什么选 FastAPI——原生 asyncio + 流式响应,和 openai 客户端的 SSE 天然对上(Flask 做流式很别扭)

另一个细节:代理启动时没有 `MINIMAX_API_KEY` 直接 `SystemExit`——**没钥匙的代理空转比失败更危险**(fail fast)。

## 关键顿悟

- **密钥防不住泄,只能不在场**:PLACEHOLDER 在攻击面里随便看,真 key 在攻击面外。所有"保护环境变量"的花招,都不如让它不存在。
- **代理是最小的策略点**:整个代理只改一个 Authorization 头,其余字节不动。协议透明让防御升级对客户端零感知——和阶段 22"换执行面不动接口"是同一个思想。
- **代理自己成为新攻击面**:它手握真 key,所以纪律是日志只记元数据、请求体永不落盘;观测侧的密钥打码(Langfuse mask)在它之外再兜一道。
