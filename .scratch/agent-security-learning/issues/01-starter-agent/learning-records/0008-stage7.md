# 0008: 阶段 7 —— memory.json 持久化

**日期**:2026-08-27

**做了什么**:`agent.py` 加 `load_memory()`(启动时 `update_state` 回灌)/`save_memory()`(退出时 `get_state` 落盘),用 `messages_to_dict/from_dict` 做消息↔JSON 转换;`config.py` 加 `MEMORY_FILE`;`.gitignore` 排除 `memory.json`。

**实测发现**:跨进程验证——会话一存 2 条,会话二(新进程)恢复后正确答出"小明",退出时又存回 4 条。`update_state` 走 add_messages reducer 是追加语义,正好用于回灌。

**遗留观察**:存的是全量消息(含工具中间产物),长期使用 prompt 会膨胀——留给路线 1/3 的记忆裁剪;LLM 调用中途 Ctrl+C 不会触发保存(loop 外的 save 够不着 asyncio.run 内部的中断),可接受,记此一笔。

**结论**:阶段 7 跑通。规格功能面全部就位,剩阶段 8 Docker(验收③)。
