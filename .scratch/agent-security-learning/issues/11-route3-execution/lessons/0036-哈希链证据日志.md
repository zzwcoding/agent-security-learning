# 0036 - 哈希链证据日志:让记录"不可抵赖"

## 1. 三问

**位置感**:`✅…38 FGA闸→✅39 串联闸→✅40 装载校验→▶️ 41 哈希链(你在这里)→42 短时令牌→43 供应链体检→…`

**这一阶段是干嘛的?** 给工具调用建一条**本地哈希链证据日志**(append-only jsonl,每条含前条的 hash),配上独立验证器;同时把 `audit.data_class` 从工具级升级为**参数级**。

**需求→设计**:Langfuse 观测面可查可看,但**可变**——8-31 重建栈就丢过全部历史。法庭式问题"这件事发生过、且记录没被改过"需要一个独立于观测系统的锚:每条记录的 hash 里揉进前一条的 hash,像乐高链一样咬死——改任何一条,后面全链验不过。

**解决什么麻烦?** 观测面回答"系统记录了什么",证据链回答"记录可信吗"。这正是图纸里 Ed25519 回执思想(路线 4 精读)的低配版:先亲手摸 hash 链,再理解签名回执比日志多证明了什么。

## 2. 全链路

```
每次工具执行完
   └─ make_tool_audit 中间件(一次遍历,双写):
        ├─ Langfuse 观测(五要素 + 参数级 data_class)  ← 观测面,可变
        └─ append_evidence → evidence-chain.jsonl       ← 证据链,append-only
             entry_hash = sha256(prev_hash + 本条规范 JSON)
                                   ▲
                   前一条的 entry_hash(首条 prev="")
 独立验证:scripts/verify-evidence-chain.py(重算全链,断点定位)
```

## 3. 跟着数据走:一条记录的一生

`filesystem-write-file({"path":"notes.txt", …})` 执行完成 →
1. 审计中间件组五要素(who/when/why/params/data_class)+ result 摘要;
2. `classify_data_class`:参数序列化后匹配敏感模式(凭证词→"凭证相关(高危)",http 词→"出网行为"…),没命中落回工具级默认——**同一工具不同参数,危险度不同**;
3. `append_evidence`:读链尾的 entry_hash 作 prev_hash → 规范化 JSON(sort_keys)→ `sha256(prev + canonical)` → 追加一行。
4. 攻击者改第 1 条的 params → 验证器重算第 1 条 hash 不符;删除第 1 条 → 第 2 条的 prev_hash 对不上 → 一样现形。

## 4. 新技术点四要素

### 哈希链(hash chain)

- **名字**:entry_hash = sha256(prev_hash + canonical_json)——区块链的最小单元。
- **作用**:任何对历史的修改/删除/重排都会让后续所有 hash 验不过——检测"有人动过记录"。
- **边界**:它不阻止修改(append-only 靠文件系统/权限),只保证**事后必被发现**;防抵赖的下一级是签名(私钥只在生成方手里),那是路线 4 的 Ed25519 回执。
- **本项目**:`agent.py` 的 `append_evidence` / `scripts/verify-evidence-chain.py`(重算全链,报第一条断点)。

### 参数级数据分级(classify_data_class)

- **作用**:工具级分级("write_file=写文件")看不出"写 .env"和"写笔记"的差别;参数模式匹配(凭证词/出网词/删除词)命中即升级,否则落回工具级——最小改动拿到参数敏感度。
- **本项目**:`agent.py` 的 `_PARAM_PATTERNS` + `classify_data_class`,审计与证据链共用。

## 5. 关键顿悟

- **"验证通过"要先审算法一致**:实测单链验证通过、双链必断——写入器漏拼 prev 前缀,单条时 sha256("")+canonical 巧合等于 sha256(canonical)。**测试要覆盖"链长>1"这个真实形态**;巧合通过比失败更危险。
- **append-only 是纪律不是魔法**:jsonl + O_APPEND 只是"惯例不覆写",真正的保证是"改了必被发现"(链)+ 生产上的文件权限/WORM 存储。
- **参数级分级是审计的灵魂**:工具级分级回答"这工具碰什么",参数级回答"这一次碰的是什么"——审计从"目录"进化到"个案"。
