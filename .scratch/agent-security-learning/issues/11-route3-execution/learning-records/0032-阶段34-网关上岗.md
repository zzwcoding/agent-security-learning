# record 0032 - 阶段 34:网关上岗(2026-09-01)

**学了什么**:ContextForge v1.0.8 Mac 原生安装路线(uv 钉 3.12 → pip 装 `mcp-contextforge-gateway` → `init_secrets --patch-env` 生成三把密钥 → 工作目录 `.env` 生效 → `mcpgateway --host 127.0.0.1 --port 4444`);网关健康面:/health 200、/ 303→登录墙、/admin/login 200、/docs 401(认证后可见)。

**卡在哪**:① 系统 Python 3.14.7 超出包的 `requires_python=<3.14,>=3.12`——uv venv --python 3.12 解决(复用本机 CPython 3.12.13);② 首次 curl 全 000——启动时先跑 SQLite 迁移,端口后监听,要留等待窗口;③ UI 和 Admin API **默认关闭**(日志 WARNING 才发现),`.env` 加 `MCPGATEWAY_UI_ENABLED=true`、`MCPGATEWAY_ADMIN_API_ENABLED=true` 后重启解决——不打开它们,阶段 35 无法注册上游、教学无看板;④ 用户登录报 `CSRF token cookie missing`——登录页种的 CSRF cookie 带 `Secure` 标志(`secure_cookies` 默认 True),Safari 在 http:// 上直接丢弃;`.env` 加 `SECURE_COOKIES=false` 解决(生产应保持默认+HTTPS)。另:登录是邮箱制 `admin@example.com`/`changeme`(首登强制改密),与 API 的 `BASIC_AUTH_PASSWORD` 是两套凭证面,SQLite `email_users` 表查证。

**结论**:网关独立家目录 `starter-agent/gateway/`(独立 venv + 独立 .env,git 均已忽略);启动脚本 `scripts/run-gateway.sh`;服务当前由 agent 代跑(后台),用户可随时 kill 后用脚本自己接管。选型时效校验通过:10 仓库 star 量级与《Agent开发分层与语言选型》8-31 表一致,ContextForge 最新 v1.0.8(2026-08-18 发布,1–2 周一版节奏未变)。细节见 lesson 0029。
