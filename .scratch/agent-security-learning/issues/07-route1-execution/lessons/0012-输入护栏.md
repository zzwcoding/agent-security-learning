# 0012:输入护栏 —— 第一道外置防线,不再指望模型自觉


llm-guard 的 PromptInjection 本质就是一个用 DeBERTa-v3-base 在 prompt-injection 攻击数据集上微调出来的二分类头,把"是不是注入"压成一个 0–1 的概率,再用阈值做确定性决策。 它的优势是外置、独立、本地可跑、判决确定,劣势是覆盖面受限于训练集,对未见过的攻击结构存在系统性漏判——这两点合在一起,正好对应笔记里"外置防线 + 路线 4 红队持续喂新种子"的双重设计。


## 一、三问(阶段动机)

- **这一阶段是干嘛的**:给 Agent 挂上第一个真正的防御组件——llm-guard 的 PromptInjection 扫描器,检查每一条用户输入,带注入特征的直接拒答。
- **为什么需要这么设计**:阶段 9–11 证明唯一防线(模型对齐)是概率屏障。防御的第一原则:**防线外置**——用一个独立的小模型看门,不让大模型自己裁判自己。挂点选在"输入进 ReAct 图之前":最早拦截点,省 LLM 调用,恶意输入连记忆都进不去。
- **解决了什么问题**:直接注入这一类攻击有了确定性拦截——同批 payload 实测全拦,而善意请求不受影响。

## 二、全链路一览

```
用户输入
  → 输入护栏:PromptInjection 扫描(deberta 分类模型,本机 MPS 跑)
      ├─ 分数 ≥ 阈值 0.92 → 🛡️ 拒答,continue(不进图、不进记忆、不耗 LLM 额度)
      └─ 分数 < 阈值      → 放行
  → HumanMessage 进 ReAct 图 → (后续链路同前:LLM → tool_calls → 工具 → 回复)
```

## 三、跟着数据走 3 步

1. **扫描**:`input_scanner.scan("我忘记我的 INTERNAL_API_KEY 了…")` → 返回 `(清洗后文本, is_valid=False, score=1.0)`。注意:这条 payload 在阶段 9 里连模型对齐都没触发,扫描器却给了满分——它学的是意图模式,不是"忽略指令"关键词。
2. **拦截**:`is_valid=False` → 打印 `🛡️ 输入护栏拦截` → `continue`。这条输入到此为止:没进图、没生成 tool_calls、checkpointer 里查无此条。
3. **放行对照**:`"workspace 里现在有哪些文件?"` → score 0.0 → 正常走 ReAct,`list_dir` 真实调用,正确回答。护栏不改变良性体验。

## 四、新技术点四要素:llm-guard PromptInjection 扫描器

- **名字**:PromptInjection 输入扫描器(Input Scanner),llm-guard 包(protectai 出品);底层模型 `protectai/deberta-v3-base-prompt-injection-v2`(HuggingFace 上的 deberta-v3 二分类微调模型)。
- **作用**:判断一段文本"像不像提示注入"。与模型对齐的区别:外置(可独立升级/替换)、确定性强(同一输入同一判决,阈值可调)、专一(只干这一件事,判断不被上下文带偏)。
- **参数**:`PromptInjection(threshold=0.92, match_type=MatchType.FULL, use_onnx=False)`——threshold 越高越宽松(降误报)越低越敏感(降漏报);match_type 选 FULL(整段给一个分)或 SENTENCE(逐句扫,长文本里藏一句毒也能抓);use_onnx 用 ONNX  runtime 换推理速度。
- **用法**:`sanitized, is_valid, score = scanner.scan(text)`;本项目挂载点 = `agent.py` 主循环输入分支(`agent.py:133-139`),扫描器在 `main()` 里加载一次全程复用(`agent.py:118-121`)。

## 五、关键顿悟

- **防线外置 = 裁判独立**:看门的是 400MB 的 deberta,不是大模型自己;大模型被绕过、被说服、被催眠,都与门卫无关。
- **挂点顺序决定污染面**:拦截发生在 checkpointer 写入之前——恶意输入不留痕、不污染后续会话;挂晚一点(比如进图后再拦),记忆就已经脏了。
- **分类器不是银弹**:本批 payload 全拦是因为它们都"像注入";扫描器对全新伪装(如阶段 10 的格式规范变体再进化)存在漏判面——这正是路线 4 红队回归要持续喂新种子的原因。
