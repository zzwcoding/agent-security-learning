### 结构规范

- **一级分支**：四层防线——① 防（护栏/注入防护）② 隔离（容器/microVM/边界）③ 身份（凭证/授权/审批）④ 审计（观测/留痕/追责）；外加 ⑤ 路线 4 已定方案（票 12，全支标 ◐ 未实践）⑥ 缺口史（7 条缺口的发现→归属→核销状态）
- **分支内展开**：攻击面 → 防御机制 → 我的实现（挂相对链接）→ 残余缺口
- **叶子节点格式**：一句话知识点 + 相对路径链接（lessons/知识卡片/deliverables/票 Answer）+ 可挂"面试一句话"
- **路线归属**以标签体现（如 `R1`/`R2`/`R3`），不作分支轴
- 内容源：deliverables route1/2/3（三件×3）、CONTEXT.md 术语、知识卡片 50+ 张、缺口清单及核销记录、票 12 Answer
