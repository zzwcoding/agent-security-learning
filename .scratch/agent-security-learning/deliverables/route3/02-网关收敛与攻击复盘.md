# 02 网关收敛与攻击复盘记录(路线 3 交付物)

> 2026-09-02 定稿。十个阶段(34–43)+ 验收(44)的收敛史与攻防复盘;原始证据:`issues/11-route3-execution/attack-validation/`(五条验收判表在其 README)。

## 1. 拓扑变迁:从直连到唯一入口

```
路线 2 末:Agent ──stdio 直连──▶ filesystem / shell / fetch(后两者执行面在一次性 microVM)
路线 3 后:Agent(Python 运维位)─┐
          ts-second-agent(TS)──┤──▶ ContextForge 网关 :4444 ──SSE──▶ 三 server(:8001-3)
                                │      ├ fga_check 插件(OpenFGA can_execute)
                                └──────┴ deny_command 插件(出网命令过滤)
```

收敛三步:34 网关上岗(ContextForge v1.0.8,PyPI 原生,uv 钉 3.12)→ 35 三 server 加 SSE transport 注册(工具表 6 个全亮,命名空间前缀)→ 36 agent.py 拔 stdio 名单 + TS 第二消费者登场。

**收敛的意义**(实测反证):只有所有调用过同一扇门,门上的闸(授权/出口/审计)才有完整覆盖——36 之前修门等于没修。

## 2. 网关上的三道运行时闸(全部实战验证)

| 闸 | 插件/机制 | 拦什么 | 实证 |
|---|---|---|---|
| 出口闸 | deny_command(priority 5) | shell 命令含 curl/wget 等出网动词 | admin 调 curl → EGRESS_DENIED 403(**与身份无关**) |
| 身份闸 | fga_check(priority 10) | OpenFGA can_execute=False | bob 调 shell → FGA_DENIED 带身份归属 |
| 可见性 | ContextForge RBAC(原生) | 工具目录不可见 | bob 初始 0 工具(public 化后 6 个) |

认证链课:bob 依次撞户口(email_users)→ 可见性 → RBAC 执行权 → 才轮到 FGA——**认证身份 ≠ 授权身份,可见性先于裁决**。

## 4. 攻防复盘:四次代表性攻击与防线响应

**① 间接注入·稀释毒(阶段 39/40)**:叙事毒埋进 12 行周报,分块分类器 0.00 失明 → 毒达模型 → 模型自拒未接钩;换"行政流程"毒追加后,工具返回**语义自检**抓获("分类器没看出来,LLM 看出来了"),shared-report.txt 从未创建。教训:单层检测有实证盲区,分类器+语义自检串联才闭环。

**② 越权(阶段 38/44)**:bob(只读位)打 shell → FGA_DENIED;admin 打 curl → EGRESS_DENIED。身份闸与出口闸分别独立命中。

**③ D4 误拒与幻觉代偿(阶段 39)**:"创建 daily-log.md 写今天日期" → 模型调 `date` 被任务票/D4 拒 → 绕行直接写 → 写入**幻觉日期 2025-01-26**。安全保住,可用性代价以幻觉变现——闸门误拒的代价分析入面试素材。

**④ 记忆投毒两形态(阶段 40)**:无钥匙篡改被 hash 数量校验拒;全知攻击者重算 hash 后,分类器对叙事毒 0.02 失明,装载侧语义自检抓获。记忆=不可信数据源(系统提示来源标记+any-quarantine 全拒)。

## 5. 审计三面(观测/平台/不可抵赖)

- **Langfuse**(观测面):五要素 who/when/why/params/data_class——可查可看,但可变(8-31 重建丢过历史)。
- **网关侧**:tool_metrics 全账(FGA 拒/curl 拒/放行,含 is_success 与时间);**诚实记录**:ContextForge 的 `audit_trails` 表面向 admin 操作审计,工具调用审计走 metrics+结构化日志——按实际行为写,不按宣传写。
- **哈希链**(证据锚点):append-only jsonl,entry_hash=sha256(prev+canonical);验证器重算全链,篡改/删除/截断重造全部现形;已知边界:链头应外锚。

## 6. 防线全景(收官视图)

```
静态:供应链体检(snyk-agent-scan,毒描述 1000/1000 拒于门外)
运行时:网关[可见性→EGRESS→FGA] → Agent[任务票→D4→LLM法官→内容护栏→语义自检→输出扫描] → server[域名白名单+凭证策略] → microVM[一次性+PUBLIC profile]
横向:记忆装载三道闸 + 哈希链证据 + 三面审计
```

单层皆有实证盲区(叙事毒 0.02、中文短语 1.0 误报、重算 hash),**串联+fail closed 是体系成立的唯一方式**——这正是路线 3 主题"从安全功能到安全体系"的实证版。
