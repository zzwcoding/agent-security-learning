# 03 缺口核销记录(路线 3 交付物)

> 2026-09-02 定稿。核销对象:`deliverables/route1/03-已知缺口清单.md` 第 2/3/4(路线 3 部分)/7 条 + 路线 2 残余"shell 公网出口"。每条:缺口 → 核销方案 → 实测证据 → 残余。

## 缺口 2:记忆装载无校验 → ✅ 已核销(阶段 40)

- **原缺口**:memory.json 无签名/无来源标记,毒记忆照装;装载在护栏链路之外(NeMo 对账)。
- **核销方案**:信封格式(逐条 sha256)+ 装载三道闸(完整性 hash → 注入分类器[仅 human]→ LLM 语义自检[仅 human])+ any-quarantine 全拒 + 系统提示来源标记(记忆=不可信数据源)。
- **实测证据**:① 无钥匙篡改 → hash 数量不符,整文件拒载;② 全知攻击者(重算 hash)→ 分类器对叙事毒 0.02 失明 → 语义自检"疑似夹带指令,已隔离";③ 对照:干净 2 条全恢复零误杀。证据:`issues/11-route3-execution/lessons/0035`。
- **残余**:信封 hash 防"无钥匙篡改",全知攻击者靠②③(语义层)兜底;生产应升级签名(非对称)。

## 缺口 3:执行层无闸 → ✅ 已核销(阶段 39,串联闸)

- **原缺口**:语义正常的恶意调用("帮我删 xxx")扫描器无话可说;write_file 参数侧无扫描。
- **核销方案**:串联闸两道——D4 规则(危险工具目标必须∈本轮用户消息,零成本免疫指鹿为马)+ LLM 法官(后果评估,允许面明确化);另加第零道任务票(阶段 42,scope 校验)。write_file 的参数(path+content)整体进入法官视野。
- **实测证据**:D4 实弹——模型调 `date +%Y-%m-%d` 被拒(目标不在消息);法官正负对照——合法写入"周五产品评审"初版误拒→调优后放行真实落盘;稀释毒场景模型被毒诱导但 secret-channel.txt 从未创建。证据:`lessons/0034`。
- **残余**:D4 误拒合法意图(date 案例)→ 模型绕行写幻觉日期——**闸门误拒把模型逼进幻觉**,可用性代价已实证记录;法官提示词依赖调优。

## 缺口 7:记忆投毒毒源未防 → ✅ 已核销(与缺口 2 合并,阶段 40)

- **原缺口**:毒效被 L3 兜住,但毒记忆仍在,每轮试图触发。
- **核销方案**:与缺口 2 同闸——装载侧三道校验后,**任何隔离发生 → 整个历史不装载(all-or-nothing)**:毒记忆不再"每轮试图触发",而是直接沉底;新会话照常,退出时干净状态重写。
- **实测证据**:攻击 B 中毒消息被隔离后历史不装载;全拒策略的副作用(历史丢失)被有意接受并记录(tool_call 配对断裂的 MiniMax 2013 实训)。

## 缺口 4(路线 3 部分):格式毒漏判 → ✅ 接线完成(阶段 40)

- **原缺口**:叙事式毒分类器块级仅 0.05;路线 3 部分为"工具返回通道加语义自检接线"。
- **核销方案**:工具返回护栏升级两级——分块分类器(快,形状)→ LLM 语义自检(意图,补盲不阻断)。
- **实测证据**:稀释毒(行政流程毒追加进 memo.txt)分类器 0.0 → 语义自检"可疑(分类器没看出来,LLM 看出来了)"→ ToolMessage 替换警告;无毒对照判"干净"放行。payload 截断限制(text[:600])与正负对照记录在案。
- **残余**:本体(分类器误/漏报率标定、payload 入 CI)仍归路线 4。

## 路线 2 残余:shell 公网出口 → ✅ 已核销(阶段 44,deny_command 网关插件)

- **原残余**(缺口 1 核销时留):fetch 有白名单,shell 内 curl/wget 仍可从 VM 触网(假数据)。
- **核销方案**:网关 `deny_command` 插件(tool_pre_invoke,priority 5 最前):命令含出网动词(curl/wget/nc/ssh…)即 EGRESS_DENIED 403——**出口策略上移网关,与身份无关(admin 同拦)**。
- **实测证据**:admin 调 `curl -s http://httpbin.org/get` → "blocked by plugin deny_command: EGRESS_DENIED - 命令含出网动词 'curl'"。证据:`attack-validation/03-gap-close/admin-curl-egress-denied.txt`。
- **残余**:黑名单是教学最小闭环;生产白名单域名+统一出口策略点(交付物 01 §6.3)。
