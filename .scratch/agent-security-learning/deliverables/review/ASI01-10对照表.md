# OWASP ASI01–10 × 本项目覆盖对照表

> 一页纸。分类标准：[OWASP Top 10 for Agentic Applications](https://www.promptfoo.dev/docs/red-team/owasp-agentic-ai/)（2025-12-09 发布，Black Hat EU）。
> 用途：面试对齐行业词汇——面试官说 ASI 编号时能立刻映射到自己做过的防线。
> 图例：✅ 实战覆盖（有代码+实测证据）｜ 🔶 部分覆盖 ｜ ⬜ 未覆盖

| ASI | 名称 | 一句话定义 | 覆盖 | 我们的对应实践（证据） |
|---|---|---|---|---|
| ASI01 | Agent Goal Hijack | 恶意内容篡改 agent 目标/决策路径 | ✅ | 三类注入演练 + L1/L2/L3 三层护栏（[route1 复盘](../route1/01-攻击复盘.md)） |
| ASI02 | Tool Misuse & Exploitation | 合法工具被用在不安全用法（参数污染/工具链操纵） | ✅ | 串联闸（D4+LLM 法官）+ 任务票 scope（[0034](../../issues/11-route3-execution/lessons/0034-串联闸-D4规则与LLM法官.md)） |
| ASI03 | Identity & Privilege Abuse | agent 继承/提权高权限凭证 | ✅ | 凭证代理（Agent 零密钥）+ OpenFGA 四元组 + 120s 短时令牌（[route3 授权模型](../route3/01-授权模型设计文档.md)） |
| ASI04 | Agentic Supply Chain | 被投毒的工具/插件/外部组件 | ✅ | 接入前静态体检，毒样本 1000/1000 抓获（[0038](../../issues/11-route3-execution/lessons/0038-供应链体检.md)） |
| ASI05 | Unexpected Code Execution | agent 生成/运行不安全代码命令 | ✅ | shell/fetch 执行面进一次性 microVM + deny_command 出口闸（[route2 边界报告](../route2/01-边界对比报告.md)） |
| ASI06 | Memory & Context Poisoning | 记忆/RAG 被投毒，跨会话操纵 | ✅ | 装载三闸 + all-or-nothing 隔离（缺口 2/7 核销，[0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)） |
| ASI07 | Insecure Inter-Agent Communication | 多 agent 间身份伪造/消息篡改 | ⬜ | 单 agent 项目未覆盖（TS client 是消费者不是对等 agent）——**诚实缺口，面试可主动讲边界** |
| ASI08 | Cascading Failures | 小错误经规划/执行/记忆级联放大 | 🔶 | 有实测案例（D4 误拒→幻觉日期代偿）；无专门防线 |
| ASI09 | Human-Agent Trust Exploitation | 利用人对 agent 的过度信任 | 🔶 | 确认门只在深化方向（harness 复刻 6/13 暂停）；误判代价对称性讨论已记录 |
| ASI10 | Rogue Agents | 被攻陷的 agent 表面正常实则作恶 | ✅ | 劫持无效化四次攻击验收（假设完全沦陷，收益为零）（[route2 验证](../route2/02-劫持无效化验证记录.md)）+ 哈希链不可抵赖 |

## 与 LLM Top 10 的关系（面试追问备料）

- ASI01↔LLM01 注入、ASI02/03↔LLM06 过度代理权、ASI06↔LLM04 投毒——Agentic Top 10 是 LLM Top 10 在"有工具、有记忆、会自主行动"后的延伸
- 我们路线 1 的三类注入 ≈ LLM01 的 agent 化；ASI 体系里独有的增量是**记忆、身份、供应链、多 agent**四个维度

## 面试一句话

"ASI 十条里我们实战覆盖了 6 条、部分 2 条；ASI07 多 agent 通信是项目边界外的诚实缺口，ASI09 人机信任的确认门我做过方案对比但选择不落地——知道为什么不建，和建过一样重要。"
