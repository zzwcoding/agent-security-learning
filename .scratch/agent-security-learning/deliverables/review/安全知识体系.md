## ① 防（护栏与注入防护）

### 攻击面：三个注入通道

- **直接注入** · 键盘通道下套 —— [0009](../../issues/07-route1-execution/lessons/0009-直接注入.md)
  - 💬 唯一防线是模型对齐时等于没有防线——对齐是概率性的
  - 注入与 SQL 注入同构：指令与数据无分离
- **间接注入** · 毒在工具返回里 —— [0010](../../issues/07-route1-execution/lessons/0010-间接注入.md)
  - 💬 企业级威胁：用户输入清白，毒从数据通道进来
  - 最强伪装 = 把恶意写进任务验收标准
- **记忆投毒** · 篡改持久记忆 —— [0011](../../issues/07-route1-execution/lessons/0011-记忆投毒.md)
  - 💬 "用户说过" ≠ "用户真说过"：最脆的信任假设
  - 持久化把注入拉上时间维度：骗一次管永久

### 防御机制：三层内容护栏（数据边界）

- **L1 输入护栏** · PromptInjection 分类器，进图前 —— [0012](../../issues/07-route1-execution/lessons/0012-输入护栏.md)
  - 💬 防线外置 = 裁判独立：大模型被说服，与 400MB 门卫无关
  - 挂点早于记忆写入，污染不进 checkpointer
- **L2 工具返回护栏** · 分块扫描 —— [0013](../../issues/07-route1-execution/lessons/0013-工具返回护栏.md)
  - 💬 稀释是分类器死穴：整段扫被平均，分块后现形
  - 但叙事毒是内容级漏判，分块也只有 0.05
- **L3 输出护栏** · Sensitive 密钥兜底 —— [0014](../../issues/07-route1-execution/lessons/0014-输出护栏.md)
  - 💬 独立于"注入是否成功"的保险：漏判只是防线后移
  - 战利品要与防御雷达配套（高熵假 key 才有回归意义）

### 防御机制：行为闸（语义层，路线 3 升级）

- **串联闸** · D4 规则 + LLM 法官 —— [0034](../../issues/11-route3-execution/lessons/0034-串联闸-D4规则与LLM法官.md)
  - 💬 FGA 答"这人能用吗"，串联闸答"这次该做吗"——有权限 ≠ 该放行
  - D4 零成本免疫指鹿为马；误拒会逼模型幻觉代偿
- **记忆装载三闸** · hash→分类器→语义自检 —— [0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)
  - 💬 三层串联补盲：hash 抓篡改、分类器抓形状、LLM 抓叙事毒
- **供应链体检** · 接入前静态扫描 —— [0038](../../issues/11-route3-execution/lessons/0038-供应链体检.md)
  - 💬 工具描述就是注入 LLM 的提示词，体检把防线工作量降到零

- **边界对比实证** · 同一逃逸探针双环境 —— [0021](../../issues/09-route2-execution/lessons/0021-边界对比-Docker-vs-microVM.md)

- **隔离级别光谱** · Firecracker/gVisor 精读 —— [0028](../../issues/09-route2-execution/lessons/0028-隔离级别光谱精读.md)

- **进程级白名单对照** · 与 microVM 正交 —— [0027](../../issues/09-route2-execution/lessons/0027-进程级白名单对照microVM.md)
  - 💬 任务面可枚举用白名单；跑任意不可信代码必须 microVM 级

## ⑦ 方法论与工程基建

### 安全方法论

- **安全姿态 = 政策存在性 × 模型执行力 × 外部强制力** —— [0016](../../issues/07-route1-execution/lessons/0016-精读chapter2攻防矩阵.md)
  - 💬 提示词层防御都是概率性的，执行层确定性校验才是兜底
- **成功率矩阵 > 孤证**；判定器看执行事实不看回复文本
- **验收标准是攻击值多少钱，不是防住没有** —— [0026](../../issues/09-route2-execution/lessons/0026-劫持无效化验收.md)
  - 总账：劫持有效，收益为零，现场完整；拒绝全绿叙事
- **规则代码化优先搬安全约束**（误判代价不对称）—— [0041](../../issues/11-route3-execution/lessons/0041-对照讨论-小模型代码化规则.md)
- **验收 = 整体打一遍**：纵深有效的前提是层间独立且各自 fail closed —— [0039](../../issues/11-route3-execution/lessons/0039-五条验收.md)

### 工程基建（攻击面认知的地基）

- **Agent = REPL**：外壳不变，改动可定位 —— [0001](../../issues/01-starter-agent/lessons/0001-项目骨架与CLI回声循环.md)
- **MCP 进程边界即信任边界** —— [0003](../../issues/01-starter-agent/lessons/0003-第一个MCP工具手动调通.md)
  - 💬 MCP 用进程边界换安全边界；stdio 子进程 env 不穿透是白送隔离
- **MCP 只是协议不是沙箱** —— [0019-tool&mcp](../../issues/09-route2-execution/lessons/0019-tool&mcp.md)
  - 💬 MCP 只挪执行位置，安全边界必须 server 自己扛
