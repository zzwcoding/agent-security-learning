# 一条消息的旅程（攻击打在旅途哪一站）

> 主轴：一条用户消息从键盘到回复的完整旅程，每站盘"攻击打在这站长什么样 / 我们放了什么闸 / 还漏什么"。
> 所有权提示：站 1–3、6–13 在**你的 Mac**；站 4–5 在**LLM 服务商的机器**（信任边界在凭证代理）；站 8–9 在**一次性 microVM**。
> 姊妹图：[安全知识体系.md（四层防线视角）](安全知识体系.md)。图例：✅ 已核销 ｜ 🔶 部分 ｜ ⬜ 未做 ｜ ◐ 未实践

## 🚉 第 0 站 · 组件进场前（消息未动，门先设）

- **攻击**：第三方 MCP server 工具描述投毒——描述就是注入 LLM 的提示词
- **闸**：接入前静态体检（毒样本 1000/1000 抓获）—— [0038](../../issues/11-route3-execution/lessons/0038-供应链体检.md)
- **闸**：网关注册即盘点，默认拒 localhost（防毒注册当跳板）—— [0030](../../issues/11-route3-execution/lessons/0030-三个server挂进网关-SSE传输与注册闭环.md)

## 🚉 第 1 站 · 人 → 客户端（CLI / TS client）

- **攻击**：用户输入直接下套；善意句式伪装；多用户冒用
- **闸**：输入护栏 L1（deberta 分类器，进图前拦）—— [0012](../../issues/07-route1-execution/lessons/0012-输入护栏.md)
  - 💬 防线外置 = 裁判独立：大模型被说服，与 400MB 门卫无关
- **闸**：双消费者身份分流（divh 运维位 / bob 只读位）—— [0031](../../issues/11-route3-execution/lessons/0031-Agent改走网关-拔直连与第二消费者.md)
- **漏**：⬜ 中文善意短语误报（"读一下"=1.0，标定归路线 4）；⬜ 拆行投毒（两行各自过闸）

## 🚉 第 2 站 · 记忆装载（Agent 启动，读 memory.json）

- **攻击**：毒记忆——"用户说过" ≠ "用户真说过"，历史消息信任等级最高 —— [0011](../../issues/07-route1-execution/lessons/0011-记忆投毒.md)
  - 💬 持久化把注入拉上时间维度：骗一次管永久
- **闸**：装载三闸——hash 完整性 → 注入分类器 → LLM 语义自检；any-quarantine 全拒 —— [0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)
- **漏**：信封 hash 防不住全知攻击者重算，靠语义层兜底；生产应升级签名

## 🚉 第 3 站 · 任务授权（Agent 内，出站前）

- **攻击**：一轮会话里被诱导做超出本轮意图的事
- **闸**：任务级短时令牌——120 秒、scope 最小、LLM 全程不接触 —— [0037](../../issues/11-route3-execution/lessons/0037-任务级短时令牌.md)
  - 💬 爆炸半径在时间（120s）和空间（scope）两轴各砍一刀

## 🚉 第 4 站 · 出本机：经凭证代理 → 推理端

- **攻击**：密钥在 Agent 环境变量/子进程继承/镜像层泄露 —— [0002](../../issues/01-starter-agent/lessons/0002-接入LLM单轮问答.md)
- **闸**：凭证代理——Agent 只持占位符，代理从 Keychain 最后一刻注入真 key 转发 —— [0022](../../issues/09-route2-execution/lessons/0022-凭证代理LLM路.md)
  - 💬 "劫持了 Agent" ≠ "拿到了密钥"——真 key 撤出攻击面
- **漏**：观测面 Langfuse key 仍在 Agent 环境（架构必然残余，收口方向=观测上报也走代理）

## 🚉 第 5 站 · 推理端（LLM 服务商的机器上）

- **攻击**：jailbreak / 对齐绕过——模型对齐是概率屏障 —— [0009](../../issues/07-route1-execution/lessons/0009-直接注入.md)
  - 💬 唯一防线是模型对齐时等于没有防线
- **闸**：**这层我们什么都不放**——模型是"不可信主体"，信任边界划在凭证代理，这是架构前提而非疏忽
- **记忆点**：注入与 SQL 注入同构——指令与数据无分离，过滤终结不了它，架构才能

## 🚉 第 6 站 · 回程入 Agent：意图翻译层

- **攻击**：模型吐出恶意 tool_calls（被骗后的"合法形式恶意内容"）
- **闸**：中间件闸链——审计最前 → 任务票验票 → D4 规则 → LLM 法官 —— [0034](../../issues/11-route3-execution/lessons/0034-串联闸-D4规则与LLM法官.md)
  - 💬 FGA 答"这人能用吗"，串联闸答"这次该做吗"
  - D4：目标须在本轮用户消息，零成本免疫指鹿为马
- **地基认知**：tool_calls 是意图非动作，翻译层是天然政策检查点 —— [0004](../../issues/01-starter-agent/lessons/0004-LangGraph-ReAct接管.md)
- **漏**：D4 误拒逼模型幻觉代偿（安全有可用性代价，已实证）

## 🚉 第 7 站 · Agent → 网关（唯一入口）

- **攻击**：绕过网关直连 server；越权调用；命令外发
- **闸**：三道运行时闸按序——可见性（RBAC）→ EGRESS（deny_command 出网动词，admin 同拦）→ FGA（can_execute 裁决）—— [0033](../../issues/11-route3-execution/lessons/0033-FGA授权闸-插件与越权攻击.md) · [缺口核销](../route3/03-缺口核销记录.md)
  - 💬 认证身份 ≠ 授权身份，可见性先于裁决
- **地基认知**：收敛先于治理——门未唯一前装闸是自欺 —— [0031](../../issues/11-route3-execution/lessons/0031-Agent改走网关-拔直连与第二消费者.md)

## 🚉 第 8 站 · MCP server（执行前最后一道）

- **攻击**：fetch 外泄密钥到任意域名；SSRF 打云元数据 169.254.169.254
- **闸**：域名白名单 + 凭证策略表同一决策点，fail closed 先于 VM 拉起（2–4ms vs 2.4s 实证）—— [0020](../../issues/09-route2-execution/lessons/0020-fetch进microVM+出网白名单.md) · [0023](../../issues/09-route2-execution/lessons/0023-凭证代理fetch路.md)
  - 💬 白名单防"去哪"，凭证策略防"带什么"
- **地基认知**：MCP 只是 JSON-RPC，无权限模型；安全边界 server 自己扛 —— [0019-tool&mcp](../../issues/09-route2-execution/lessons/0019-tool&mcp.md)

## 🚉 第 9 站 · 执行面（一次性 microVM）

- **攻击**：命令逃逸读宿主/扫内网/提权；内核 0day
- **闸**：独立内核 + 用完即焚 + PUBLIC profile 网络兜底（私网/元数据 exit 7）—— [0018](../../issues/09-route2-execution/lessons/0018-microsandbox最小闭环.md) · [0019](../../issues/09-route2-execution/lessons/0019-shell工具进microVM.md)
  - 💬 容器哲学捆紧内部，microVM 哲学整个扔掉——防御预算花在边界更值钱
  - 💬 "一次性"比"加固"便宜：从根上消灭持久化
- **对照**：进程级白名单管"能跑什么"，microVM 管"跑的地方能碰到什么"，正交不竞争 —— [0027](../../issues/09-route2-execution/lessons/0027-进程级白名单对照microVM.md)
- **理论**：攻击面 = 暴露给不可信代码的代码量（Firecracker/gVisor 精读）—— [0028](../../issues/09-route2-execution/lessons/0028-隔离级别光谱精读.md)

## 🚉 第 10 站 · 工具返回回程（间接注入主入口）

- **攻击**：毒在工具读到的文件/网页里，用户全程善意 —— [0010](../../issues/07-route1-execution/lessons/0010-间接注入.md)
  - 💬 最强伪装 = 把恶意写进任务验收标准
- **闸**：L2 分块扫描（稀释是分类器死穴）+ 语义自检补盲（叙事毒）—— [0013](../../issues/07-route1-execution/lessons/0013-工具返回护栏.md) · [0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)
- **漏**：🔶 叙事毒分类器 0.05 失明，语义自检已接线，标定归路线 4

## 🚉 第 11 站 · 最终回复出站

- **攻击**：密钥/敏感数据随回复出门（上游全失守的最后一道）
- **闸**：L3 输出护栏 Sensitive 兜底 —— [0014](../../issues/07-route1-execution/lessons/0014-输出护栏.md)
  - 💬 独立于"注入是否成功"的保险；战利品要与防御雷达配套（高熵假 key）

## 🚉 第 12 站 · 落库（记忆写回 memory.json）

- **攻击**：PII 明文落盘成持久资产
- **闸**：Presidio Analyzer→Anonymizer 落库前脱敏 —— [0024](../../issues/09-route2-execution/lessons/0024-Presidio记忆落库脱敏.md)
  - 💬 消毒点选出口不选入口——入口护栏会误伤，出口拦不可逆动作
