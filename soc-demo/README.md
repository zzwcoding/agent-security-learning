# SOC 数字员工（soc-demo）

为被告警淹没的 SOC 提供一名"数字员工"：自动分诊告警、调查取证、沉淀知识，危险动作永远等人点头。

- 需求与验收口径：`specs/` 与 PRD（见下方文档地图）
- 一键启动：`docker compose up`（阶段 0.2 起可用）
