M3-M8 编排与 workers —— 系统的大脑

干什么：supervisor 图编排（LangGraph.js）拉起四个 worker 子图：分诊 M4 → 调查 M5 → 富化 M6 → 沉淀 M7；对话 Copilot M8 也在这里。

  • 硬规矩：supervisor 自己不持工具、不做安全判断，只调度；worker 之间不直接对话，靠共享 Case 资源层协作
  • 审批：L2 高危动作在图里 interrupt() 挂起，等人点头才 resume
  • 验收：杀进程重启后审批状态可恢复；信封 hash 篡改必拒；超 token 预算强杀
  • 权限：每个 worker 只持任务级最小 scope 票，分诊 agent 物理上没有遏制工具的票
