告警源 —— 数据从哪来

真实世界对应物：公司每台服务器上的 Wazuh 探针，24 小时产出告警 JSON。我们没有真实外部环境，所以用混合策略造数据：

  • 现成采集：Wazuh 官方仓库 ruleset 测试样本、官方文档样例、路线 1-3 实测语料
  • 官方工具自产：可选 real-wazuh profile 起容器，logtest 喂真实日志产出真告警
  • 攻击变体人工改造：把注入载荷植入 srcuser/full_log/url 等攻击者可控字段（独创资产，全网没有现成数据集）

进系统的方式（刻意设计）：数据落盘在 fixtures/alerts/，但绝不直接塞数据库——由回放脚本扮演外部世界，HTTP POST 推进 webhook，走和真实 Wazuh 完全相同的门。推模式（有事就推），不做定时轮询。

回放载体：scripts/replay.ts 几十行 CLI，可配速率；Web 告警列表页有同款回放按钮。不进 compose，是「非运行时件」。
