M1 告警接入 —— 告警进系统的唯一入口

干什么：收 webhook → source+sourceRef 去重（重复时 occurrences+1，不新建不重复触发）→ Wazuh 字段映射成 Alert → full_log/data.* 打上不可信标记 → 发事件喊流水线开工。

本质定位：门卫 + 翻译 + 打标——入口归一化。不管什么来源，过了这扇门都变成统一格式、统一去重身份、贴上"这是数据不是指令"标签。纯确定性代码，无 LLM。

  • 接口：POST /api/v1/webhooks/alerts；POST /internal/replay（fixture 回放）
  • Seam：写库走 M2 REST（可换内存 stub 测试）；去重唯一约束在 M2 SQLite 兜底
  • 验收：同一 fixture 连推 3 次只建 1 条；7 类具名 fixture 映射全过
  • 全是确定性代码，无 LLM
