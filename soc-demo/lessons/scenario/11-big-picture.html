① 这张图是什么

场景 11「第二个业务零增量」的代码落点索引：主视觉线是数据模板 → 装载 → 循环 → 零增量闸—— 第二个业务（应急取证）的全部家当是一张预案卡 JSON（句式族/菜单子集收窄 host 维度/轮次上限/ 既定查询计划/遏制建议文本），内容层装载包只投影机制四字段进循环；右侧机制层（m14 领地）画成 黑盒——第二业务落地时它零行增量，蹲在边界线上的零增量闸（T20）用「diff × 领地交集为空」 把这条主张变成 CI 二值。菜单收窄是图上最粗的一条红线：ir 菜单 5 件之外，全仓 32 件在册工具的 其余 27 件（含 web 维度 web_access_query、L2 的 isolate_host）对 planner 100% offmenu_tool 拒。 与 S7 的呼应：S7 讲「加工具要登记」，S11 讲「加业务只要数据」。本场景数字：4 步 / 15 个节点 / 3 道安全闸（红描边 🛡️）。（八场景全局数字见 0-0.md，不在这张图里。）

② 怎么读

  • 配色：蓝框 = 普通节点；红描边 + 🛡️ = 安全防护节点（防什么写在节点里）； 暗灰虚线 = 说明性节点（机制层领地黑盒，非数据流）；cylinders（柱形）= 存储表。
  • 线型：实线 = 主流程调用；虚线 = 响应 / 只读 / 非主流程；红虚线 = 跨容器出站调用（标签带 跨容器→服务:端口；进程内/同容器调用不出红）。
  • 箭字前缀：请求 … = 出站 HTTP；响应 … = 回包；读 … = 只读依赖；事件 … = 落盘事件总线扇出（禁轮询）。
  • 子图标题带 进入 / 节拍 / 退出 三段——先看它再进节点。节点只写「做什么」，「为什么 / 下游」看下面的明细表与对应文章 11-0..11-4（文档每站开头的 📍 行 = 本图节点 ID）。

③ 最常被问的入口（5 条）

  1. 想看「第二个业务的原料长什么样」→ IR_TEMPLATE → HUNT_PACK → REGISTRY（11.1）。
  2. 想看「闸怎么知道你越界」→ ZGATE 的两条虚线：绿样本（内容层增量）与红样本（领地内一个字节）（11.2，捣乱②实测 exit 1）。
  3. 想看「4 轮轨迹从哪来」→ FAKE_LLM（菜单签名回族 → 查 waves 波表 → 槽位渲染）与 ROUND_CHAIN（11.3 真栈实测）。
  4. 想看「27 件工具怎么 100% 拒」→ MENU_GATE → OFFMENU27（11.4）。
  5. 想看「遏制建议为什么不变成动作」→ CASE_HIT（只进 note 文本，零 ApprovalToken，INV-3/9）。
