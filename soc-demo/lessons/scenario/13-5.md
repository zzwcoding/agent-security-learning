### 捣乱①的答案：哪个环节拦/不拦

| 环节 | 拦不拦 | 为什么 |
|---|---|---|
| graph_query 读面 | **不拦** | 读面只认 status 字段——它信任数据源，不审查数据源怎么来的（读面没有"批文核对"这个职责） |
| committed 测试 | **拦（事后）** | T22 的 total 断言钉着 fixture 内容——数据也有回归网，但这是**仓库内**的网 |
| hypothesis_register 写面 | **拦（事前）——这才是 INV-5 的牙** | 唯一写通道只产 proposed，**没有任何代码路径能写出 approved**；"翻面"只能由人审通道（票 83）做 |

所以捣乱①教的不是"防线有洞"，是**信任边界**：fixture 是 git 布景，能改它=有仓库写
权限=布景外世界（同"能改任何 fixture/源码"）。真系统里没有"塞 fixture"这条路——
数据面在 weknora 真仓的库里，**进库的合法通道只有 soc-demo 包层的人审闸**（包层即
闸门），非法通道是"攻破 weknora 仓本身"——那是另一个威胁模型（如同攻破 chroma 容器）。
INV-5 防的是**系统自己的写路径自动发布**（13.4 的三连），不防拥有数据面 root 的攻击者
——防后者靠的是部署边界与审计（真仓对接后的摄取留痕，票 83 回填段）。

### 站 1 · seam：一条已经焊好的换件缝

env 开关 `WEKNORA_URL`（未设=stub 逐字节不变，jiaotu profile 同款开关纪律）。

### 站 2 · 两仓分工红线：weknora 侧零安全闸是架构不是偷工

票 83 铁律原话："weknora 侧不做任何安全闸（**两仓分工红线**：它只管知识平面）；
**包层即闸门**——soc-demo 侧人审/扫描/审计一件不能省"。为什么这么分：

- **专业面**：weknora 专心做知识（检索/图谱/摄取），安全语义是 soc-demo 的既有资产
  （INV 家族/闸体/审计 sink 全在包层现成）。知识仓再发明一遍人审闸=两套安全语义
  漂移（票 43 教训：安全语义只许一份拷贝）。
- **闸的唯一性**：INV-5 的语义"未人审不进检索面"（[TERMS「KB 账面 vs 检索面」](TERMS.md)条的狩猎侧推广）必须由**一个**地方裁决。若 weknora
  也拦一道，两道闸对"什么算已审"的口径迟早分叉；只留包层一道，口径永远单一。
- **fail-closed 的归属**：weknora 挂掉时包层怎么反应（查询失败 ≠ 无结果）——票 83
  验收行原话"weknora 挂掉时 fail-closed（INV-1：查询失败 ≠ 无结果，降级语义测试绿）"。
  降级语义在包层实现，weknora 不可达=狩猎退回无记忆基线（13.3 站 1 的形态），绝不
  把"查不到"当"没有记忆"喂给 planner。

## 场景题闯关（本步 2 题 + 收官）

**Q1：真源对接后（票 83），graph_query 改打 weknora 的 /graph/query。假设真仓某天
宕机，这个工具的返回该是什么？"返回 total=0"和"抛错"各会教会 planner 什么错的东西？**

<details><summary>答案（点击展开）</summary>

按 fail-closed（INV-1："查询失败 ≠ 无结果"）必须**抛错**而不是返回 total=0。
"返回 total=0"会把"知识平面不可达"冒充成"没有记忆"——planner 据此做出的不是
"无记忆退回基线"的降级，而是"该对象连过什么案=查无"的**事实误报**：图谱说 web01
干净，可能与真相反（旧案边明明在，只是查不到）。"抛错"则让错误沿既有 fail-closed
链走：签名契约后的执行异常=子 run failed 可观察 → judge 按"failed 子报告不是证据"
处理（hunt-pack.ts:175）→ 不带病收敛、进 gap 换组合。这正是票 83 验收行
"weknora 挂掉时 fail-closed（INV-1：查询失败 ≠ 无结果，降级语义测试绿）"的教学翻译：
**"空"是一个事实判断，"查不到"是一次执行失败——两者在 API 形状上必须可区分**
（错误走异常/非 2xx，空走 total=0），混用=知识平面撒谎。</details>

**Q2（收官）：S9 教循环怎么转，S10 教权限怎么收，S11 教业务怎么加，S12 教自己怎么
自证，S13 教记忆怎么进、毒怎么拦。五个场景合起来，编排循环战役的"一句话总纲"
是什么？**

<details><summary>答案（点击展开）</summary>

一条主动狩猎环，五种约束下的同一个机制：**怀疑立项（S9 生命周期，[TERMS「侦查怀疑书」](TERMS.md)条）→ 菜单内自主
拆单（S10 两票围栏）→ 业务只是数据（S11 零增量）→ 好坏机器判卷（S12 自证）→
记忆扩消费面而毒进不了面（S13 知识平面）**。贯穿五景的三条不变式线索：机制层
（m14）从 S9 到 S13 零业务 if/else——一切行为差异来自数据（菜单/waves/剧本库/图谱）；
一切 LLM 决策面被双闸夹住（菜单闸+铸票缝、schema 验型+消毒、judge 半判据+签名复核）；
一切写通道有唯一入口+唯一状态机（怀疑书五态、register 只写 proposed、审计五要素）。
S13 的"记忆"没有突破任何一条——它以数据进菜单（13.1）、以布景供查询（13.2/13.3）、
以真闸拦投毒（13.4）、以 seam 换真源（13.5）：**进化的是消费面，不变的是闸门**。</details>
