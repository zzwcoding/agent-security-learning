# 场景导览总纲 · soc-demo 学习阶段

## 文章模板（六节，详见 skill 场景导览模式节）

**风格铁律（先读）**：读者是信息化小白——通篇大白话，每个技术词首次出现配比喻，**比喻优先取自我们自己的 SOC 业务**（告警=报案电话、分诊=预检分诊台、任务票=保安队长的手令、焚毁=一次性密令用完即毁），泛生活比喻只在业务内找不到对应时才用；例子直接用本项目的真实数据（真告警、真 run_id）；每段写完自检"读者能用自己的话复述吗"，不能就重写。

操作（含位置感）→ 调用链（**ASCII 全景图后按"站"逐站带真实代码走**：每站 = 大白话叙述 → 代码/配置原文逐字引用（标文件+行号范围，仓库根相对路径 `soc-demo/…#L行号` 可跳转链接，行号实测核对，注解写块外不混进引用块）→ 繁琐细则转标注"伪代码"的块并给真实行号指针；样板 = `1-1.md`）→ 服务与中间件卡（≤2 张：自研/开源、配置、市面替代、为何选、业务上怎么选）→ 防线对号（INV/契约）→ 亲手验证（必选，命令+预期特征）→ 捣乱实验（必选）。
