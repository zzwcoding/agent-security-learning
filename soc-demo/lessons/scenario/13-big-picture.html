② 怎么读

  • 配色：蓝框 = 普通节点；红描边 + 🛡️ = 安全防护节点（防什么写在节点里）； cylinders（柱形）= 数据文件；暗灰虚线 = 说明性节点（seam 落点/未对接外仓，非数据流）。
  • 线型：实线 = 主流程调用；虚线 = 响应 / 只读 / 非主流程；跨容器出站调用在标签里 带 跨容器→服务:端口（本图 3 条，全去 case-backend:3002）。
  • 箭字前缀：请求 … = 发起执行；读 … = 只读依赖； T+… = 时序前缀；响应 … = 返回面。
  • 子图标题带 进入 / 节拍 / 退出 三段——先看它再进节点。节点只写「做什么」，「为什么 / 下游」看下面的明细表与对应文章 13-0..13-5（文档每站开头的 📍 行 = 本图节点 ID）。
