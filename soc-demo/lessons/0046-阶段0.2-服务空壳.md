# 0046 · 阶段 0.2：七个服务空壳 + compose 一把起

## 三问

- **终极目标**：PRD §4.1 的 C1–C7 组件全部以 docker-compose 服务形态存在。本阶段让每个服务有一个"能起、能答 /healthz"的空壳。
- **为什么现在做**：sdd-flow 的纪律是 CI 和骨架先于业务代码——空壳跑通了，后面每个模块（M1–M12）才有往里长的格子。
- **解决什么麻烦**：把"环境搭不起来"这类风险清零在第一天；同时把端口规划、依赖顺序（depends_on）这些拓扑决策固化成代码。

## 全链路一览

```
宿主机                     docker compose 网络
  │  curl :3001/healthz ──► ingest（Fastify 空壳，Wazuh 接入口的家）
  │  curl :3002/healthz ──► case-backend（TheHive 风格案件后端的家）
  │  curl :3003/healthz ──► agent（supervisor+4 worker 的家；等 case-backend/guards 健康才起）
  │  curl :8001/healthz ──► guards（llm-guard + Presidio 的家）
  │  curl :8002/healthz ──► gateway（RBAC/FGA/铸币的家，占位实现待 ADR 0001）
  │  curl :8000/api/v2/heartbeat ──► chroma（官方镜像）
  │  浏览器 :5173 ──► web（Vite+React，页面显示阶段标记）
```

## 踩坑实录（本阶段真正值钱的部分）

1. **Docker daemon 没起**：`docker compose build` 报 socket 不存在。`open -a Docker` 启动桌面版即可；注意 `cmd | tail` 会吃掉真实退出码，失败要看完整日志。
2. **pnpm 10 的 minimumReleaseAge 供应链闸门**：lockfile 里有几个包发布不足 24 小时（@types/react-dom、fastify、postcss 等），Docker 里 `--frozen-lockfile` 直接拒绝。解法：`pnpm-workspace.yaml` 里 `minimumReleaseAge: 0`（pnpm 10 的设置要放 workspace yaml，`.npmrc` 只作旧版兜底）。替代控制 = lockfile 入库 + PR 审 diff。
3. **pnpm 10 默认拦依赖安装脚本**：esbuild 的 postinstall 被拦报 `ERR_PNPM_IGNORED_BUILDS`。解法：workspace yaml 加 `onlyBuiltDependencies: [esbuild]`。
4. **镜像内外 pnpm 版本不一致**：本地改过设置有效、容器里照旧报错——corepack 没带版本锁定，容器里跑的是另一个 pnpm。解法：根 `package.json` 加 `packageManager: pnpm@10.34.3`，corepack 照着装。
5. **healthcheck 用 localhost 被 IPv6 坑**：alpine 里 localhost 优先解析 ::1，Fastify 绑 0.0.0.0（IPv4）→ 容器内 wget localhost 永远 refused，但服务其实活着。解法：健康检查一律 `127.0.0.1`。
6. **chroma 官方镜像没有任何 HTTP 客户端**（无 wget/curl/python）：做不了容器内 healthcheck，撤掉，改宿主机 curl 验证。

## 关键顿悟

- **空壳阶段踩的每个坑都是地基坑**：供应链策略、版本锁定、IPv6 解析——这些在业务代码进来之前暴露，成本最低。
- **版本锁定要贯穿三层**：本机、CI、镜像。`packageManager` 字段就是干这个的。
- **健康检查也是代码**：它和环境（DNS 解析、镜像里有什么二进制）强相关，不能想当然。

## 亲手验证

```bash
cd /Users/divh/Downloads/安全评估agent/soc-demo
docker compose ps                        # 应看到 7 个服务 Up，6 个 healthy（chroma 无检查属正常）

open http://localhost:5173/              # 页面显示"阶段 0.2 跑通"

```

捣乱实验：把 `docker-compose.yml` 里 ingest 的 healthcheck 改回 `localhost`，`docker compose up -d --force-recreate ingest`，一分钟后看它变成 unhealthy——亲身体会坑 5。
