# 学习简记 0005:阶段 5 — 加固 Docker 沙箱与协议化校验

**日期**:2026-08-31
**学了什么**:
- 沙箱 = 隔离病房 + 协议:宿主经 stdin/stdout JSON 与一次性容器对话,只认合规 JSON,其余(超时/OOM/docker 缺失/协议异常/输出超限)一律 SandboxError → 灯表全灭,fail closed。
- 内容寻址镜像:镜像名 = sha256(Dockerfile+runner)[:12],改一字节强制重建,镜像与源码绑定,防"镜像被动手脚"。
- 加固 flag 分组记:网络(--network none/--ipc none)、文件系统(--read-only + noexec tmpfs)、身份(--user nobody + --cap-drop ALL + no-new-privileges)、资源(--pids-limit/--memory-swap 要和 --memory 一起限,否则 swap 绕过)、痕迹(--rm + --log-driver none)。
- Dockerfile ENTRYPOINT 用 python -I(隔离模式,不加载用户 site/环境)。
- 实测:镜像 self-modify-replica/sandbox:bf8ab8607cfd 构建成功,往返 JSON {"source_bytes": 778, "trajectories_seen": 3},--rm 无残留容器。

**卡在哪**:无。已知简化:参考版有界读线程流式限幅 → 本复刻 communicate+事后限幅(处置语义一致,恶意容器可先占内存),记入 lesson 0005 诚实标注,阶段 12 收官复核。

**结论**:数据流闭合(候选+轨迹 → 沙箱 → 回传 JSON → 灯表 sandbox_execution ✓)。下一步(阶段 6):容器内语义检查上三灯(public_api_compatible/failure_replay/nonretryable_circuit)。
