# 学习简记 0012:阶段 12(收官)— 执行面对照

**日期**:2026-08-31
**学了什么**:
- 执行面可替换 = 协议化设计的红利:同一 runner、同一 SandboxError 契约、同一灯表,三种候选在 Docker/microVM 绿灯 100% 一致(7/7、4/7、7/7),耗时同级(microVM 首跑 0.44s 含引导)。
- 两种隔离哲学实测:共享 linuxkit 内核+捆死权限(nobody/零cap/只读/全断网) vs 独享内核+内里 root 放权+宿主零可见+网关默认拒私网。内核 0day 场景下 Docker 纵深同归于共享内核,microVM 爆炸半径只有一台即焚 VM。
- 收官必答(复盘落定):选一次性 microVM;决定性维度=隔离级别+工程成本;网络短板用主线阶段 23 网关白名单补齐;失败语义已证等价;Docker 降备选。
- 踩坑二则:① microVM 写 runner 忘喂 stdin→cat 挂起→ExecTimeoutError→SandboxError(fail closed 新后端开箱生效);② Docker ENTRYPOINT 参数陷阱——命令行追加给 ENTRYPOINT 而非替换,探针要用 --entrypoint 显式覆盖;harness 自身也要验证。
- 审计提示:microVM 内 root 满血是设计不是漏洞,审计信号要从"容器内提权"换成"出网白名单命中"。

**卡在哪**:两个坑均当场修复并记录;探针 Docker 首跑空输出靠读 _docker_command 结构定位。

**结论**:12 阶段全部完成,16/16 验收 gate + 双后端对照 + 复盘落盘。对照复盘已给不和稀泥结论,可供主线 deliverables/route2/(阶段 33)引用。复刻收官。
