# 学习简记 0003:阶段 3 — 确定性提案与物理隔离

**日期**:2026-08-31
**学了什么**:
- 候选与稳定物理隔离:候选只写 output/candidate/,demo 读回 stable 逐字节比对("未被改动:True")——隔离是可验事实,不是设计口号。
- 修复是三段协调的最小替换:PAYMENT_DECLINED 入 NON_RETRYABLE_CODES 表 + should_retry 认账 retryable + 熔断对永久错误立即跳闸(consecutive_failures>=1)。改函数必须连着改它查的表,否则行为不闭环。
- _replace_once 要求旧块恰好匹配一次,0 次或多次都抛错(fail loud):补丁只对"认识的"稳定版生效,版本漂移宁可失败不乱改。
- 新技术点:difflib.unified_diff 要喂"保尾换行的行序列"(splitlines(keepends=True)),返回行迭代器需 join。

**卡在哪**:无。参考版 candidate_from_source 的 patch_size / impact_prediction / generator_metadata 属于阶段 8 manifest,按"不超前"暂缓(函数留了注释标记)。
