# 0008: 全流程安全总账(2026-08-31)

**学了什么**:收官复盘,把 0001-0006 从安全视角串成一份总账(lessons/0007)。做法仿照"自修改 agent 复刻"项目的 0013 结构:威胁模型九条攻击路径(W1-W9,其中实测五条:直接注入、格式伪装毒、输入侧泄密、输出侧编造密钥、账单/误拦;不设防两条:工具返回、记忆装载;未实测两条:话题偏离、幻觉)、六条横切原则、迁移表八行(逐行标注实测/精读)、诚实边界六条、上线检查单十项。

**卡在哪**:无新实验,纯装订。唯一要守的纪律是不把精读推断写成实测——迁移表和威胁模型里每行都标了证据等级;幻觉、话题偏离本项目确实没做实验,如实写"未覆盖"。

**结论**:总纲一句话——五道闸位置固定、机制可插拔;self-check 拦得住主模型看得懂的坏,清单漏词即漏防、账单 ×3,工具返回与记忆装载两条通道不经过任何闸。最重要的两条收获:①默认输出清单没有密钥条款,T1 实测放行编造假密钥、补一条即拦——清单即策略,漏词即漏防;②护栏先算账再上线(双闸 ≈ ×3 调用/token/延迟,被拦只花 1 次调用),按闸位混搭:便宜机制站常规岗,语义机制守分类器天花板。
