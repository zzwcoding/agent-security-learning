# Agent 安全学习笔记总结

## 1. MCP 协议的信任边界
MCP 协议将工具调用标准化为跨进程接口，server 与 client 之间存在天然的信任边界。这是安全防护的第一道防线。

## 2. ReAct 循环的执行分离
模型生成的 tool_calls 只是"意图"，真正执行的是框架层。政策检查点位于翻译层，实现了意图与执行的分离。

## 3. 工具风险与防御策略
- shell 和 fetch 等工具存在提示注入风险，可直接转化为命令执行和数据外泄
- 防御关键点：协议边界(MCP 网关)、进程边界(沙箱)、数据边界(脱敏)
- 多轮对话的"记忆"本质是客户端重发历史消息，模型本身无状态
