# 攻击者视角：我要怎么打穿这个 Agent

> 主轴：攻击者的**目标**。每个目标下钻攻击路径，每条路径走到"撞在哪层墙"为止。
> 姊妹图：[防线视角](安全知识体系.md)（盾的说明书）｜ [消息旅程](安全知识体系-消息旅程.md)（消息流）。
> 本图同时是路线 4 红队恢复时的作战地图。图例：✅ 此路已封 ｜ 🔶 部分拦 ｜ ⬜ 已知缝隙

## 🎯 目标 A：偷密钥（ik-live 战利品）

### 路径 A1 · 直接注入：让用户输入骗 agent 读 .env
- 卡通 jailbreak 被对齐拒；**自然请求得手**（"我忘了 key 帮我读"）—— [0009](../../issues/07-route1-execution/lessons/0009-直接注入.md)
- 撞墙：✅ L1 输入护栏（分数 1.0）—— [0012](../../issues/07-route1-execution/lessons/0012-输入护栏.md)
- 缝：⬜ 善意句式误报倒逼阈值下调后，边界话术有博弈空间（路线 4 标定）

### 路径 A2 · 间接注入：毒藏在 agent 会读的内容里
- 文件向量三轮迭代（格式规范毒得手）、网页向量一击即中 —— [0010](../../issues/07-route1-execution/lessons/0010-间接注入.md)
- 撞墙：✅ L2 分块扫描（稀释现形）+ 路线 3 语义自检补盲 —— [0013](../../issues/07-route1-execution/lessons/0013-工具返回护栏.md) · [0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)
- 缝：🔶 叙事毒分类器 0.05 失明，语义自检是唯一兜底（单点）

### 路径 A3 · 记忆投毒：篡改 memory.json 一劳永逸
- 零迭代得手——历史消息信任等级最高 —— [0011](../../issues/07-route1-execution/lessons/0011-记忆投毒.md)
- 撞墙：✅ 装载三闸（hash→分类器→语义自检）+ all-or-nothing —— [0035](../../issues/11-route3-execution/lessons/0035-装载校验与语义自检.md)
- 缝：⬜ 全知攻击者重算 hash 后只剩语义层；生产应升级非对称签名

### 路径 A4 · 凭证走私：借白名单域名夹带密钥
- 借 httpbin 夹带 `{{SECRET:MINIMAX_API_KEY}}` —— 被凭证策略拒（名字未授权给该域名）—— [0023](../../issues/09-route2-execution/lessons/0023-凭证代理fetch路.md)
- 撞墙：✅ 白名单防"去哪" × 凭证策略防"带什么"，同一决策点

### 路径 A5 · 直接翻进程环境/文件系统
- 撞墙：✅ 密钥不在场——全可见面枚举零命中，真 key 只在 Keychain+代理 —— [验证记录](../route2/02-劫持无效化验证记录.md)
- 💬 "劫持了 Agent" ≠ "拿到了密钥"

## 🎯 目标 B：执行任意命令 / 逃逸

### 路径 B1 · run_command 任意命令
- 撞墙：✅ 一次性 microVM——VM 内 root 满血但宿主零可见、用完即焚 —— [0019](../../issues/09-route2-execution/lessons/0019-shell工具进microVM.md) · [逃逸探针七连](../route2/01-边界对比报告.md)
- 缝：⬜ VM 内公网出口（curl 出网）被路线 3 deny_command 黑名单封死；白名单化是深化方向

### 路径 B2 · 内核 0day 穿透
- 撞墙：✅ 独立内核——逃逸面 = 极简 VMM 而非整颗宿主内核 —— [0028](../../issues/09-route2-execution/lessons/0028-隔离级别光谱精读.md)

## 🎯 目标 C：外泄数据（egress）

### 路径 C1 · fetch/http_post 外发
- 撞墙：✅ 工具层白名单 fail closed（2–4ms，VM 不拉起）+ 网络层 PUBLIC 兜底（私网/元数据 exit 7）—— [缺口 1 核销](../route2/03-缺口1核销记录.md)

### 路径 C2 · shell 内 curl/wget 外发
- 撞墙：✅ 网关 deny_command——出网动词即拒，**与身份无关（admin 同拦）** —— [缺口核销](../route3/03-缺口核销记录.md)

## 🎯 目标 D：越权操作（多用户/身份冒用）

### 路径 D1 · bob（只读位）调 shell
- 撞墙：✅ 四道关卡依次撞——户口 → 可见性 → RBAC → FGA（FGA_DENIED 带身份归属）—— [0033](../../issues/11-route3-execution/lessons/0033-FGA授权闸-插件与越权攻击.md)
  - 💬 认证身份 ≠ 授权身份，可见性先于裁决

### 路径 D2 · 有权限但干超本轮意图的事
- 撞墙：✅ 任务票（120s/最小 scope）→ D4 规则 → LLM 法官 —— [0037](../../issues/11-route3-execution/lessons/0037-任务级短时令牌.md) · [0034](../../issues/11-route3-execution/lessons/0034-串联闸-D4规则与LLM法官.md)
- 缝：⬜ D4 误拒逼模型幻觉代偿（用可用性换安全的实证案例）

## 🎯 目标 E：抹掉痕迹 / 抵赖

### 路径 E1 · 篡改/删除/重排审计记录
- 撞墙：✅ 哈希链——任一改动全链验断 —— [0036](../../issues/11-route3-execution/lessons/0036-哈希链证据日志.md)
- 缝：⬜ 链头未外锚——截断重造需链外手段发现（归收尾）

### 路径 E2 · 攻击被拦就不留痕
- 撞墙：✅ 拦截事件手动补录进 trace——"有人来过但被拦"可查 —— [0017](../../issues/07-route1-execution/lessons/0017-langfuse本地接入.md)

## 🎯 目标 F：绕过单层的技法库（红队弹药）

| 技法 | 对哪层有效 | 答案 | 状态 |
|---|---|---|---|
| 稀释（毒埋进长文） | 整段分类器 | 分块扫描 | ✅ |
| 叙事伪装（格式规范毒） | 分块分类器 0.05 | LLM 语义自检 | 🔶 单点兜底 |
| 拆行投毒 | 逐行护栏 | 会话级聚合闸 | ⬜ 路线 4 |
| 重算 hash | 完整性校验 | 语义层兜底/签名 | ⬜ 深化 |
| 误拒诱导 | D4 规则 | 法官调优 | 🔶 幻觉代偿实证 |
| 良性外衣+延迟触发 | 分类器天然盲区 | 无 | ⬜ 路线 4 种子 |
