⓪供应链体检站 0 · 组件接入网关前

做什么：第三方 MCP server 接入前，用 snyk-agent-scan 审工具描述——描述 = 给 LLM 的提示词 = 攻击面。毒样本实测 1000/1000 抓获；人工复核三红旗（功能不匹配/要求隐瞒用户/敏感数据进参数）。

机制：静态体检 + 动态防线双层——体检把毒拒在门外，漏网的进运行时四层闸；体检是把防线工作量降到零，不是替代防线。注意：拉描述必须启动受检 server（X009），体检本身要逐个询问授权。

LangChain/LangGraph 实现：普通 TS——接入流程里的人工步骤/CI 脚本（忽略），不在图的运行时路径上。

🚪登录与能力圈阶段 0 · 会话开始前一次

做什么：用户登录 → Keycloak 铸门票（铸币时刻①）→ 拿门票问网关 → 验票 + RBAC 可见性 → 下发"工具目录 + 分级表" → 可见工具注册进图。

机制：模型从出生在能力圈里——看不见的工具连名字都不知道，是第一道不动声色的闸。

LangChain/LangGraph 实现：登录与换票是普通 TS（OAuth2 fetch，忽略）；注册进图 = 建图时按目录过滤 tools 数组再传入 createReactAgent——能力圈即 tools 实参。

①输入护栏站 1 · 人→客户端

做什么：用户消息进图之前查提示注入；多 Agent 端（TS 客户端 ×N）共用同一护栏微服务。

用什么：TS 侧 fetch → 自建 llm-guard 微服务（FastAPI 包 PromptInjection，deberta 本地推理）。

机制：拦在进图前，毒输入不进图、不进 checkpointer、不污染记忆；被拦也留痕。

LangChain/LangGraph 实现：普通 TS——主循环 graph.invoke() 之前的 if 判断（忽略）。故意不进中间件：beforeModel 触发时消息已入图状态，太晚。

②记忆装载 · 进图站 2

做什么：checkpointer 按 thread_id 带出历史；历史是"昨天埋的雷"，装载 = 受审通道，三道闸串联：

②a hash 完整性：TS 侧 crypto.subtle 逐条 sha256 对信封——防无钥匙篡改；数量不符整文件拒载

②b 注入分类器：走 llm-guard 微服务（HTTP）——抓形状毒；叙事毒它实测失明（0.02）

②c LLM 语义自检：判官 LLM（一词裁决"干净/可疑"）——抓分类器失明的叙事毒；只审 human 消息

机制：任一隔离 → 整个历史不装载（all-or-nothing：逐条剔除会破坏 tool_call 配对）；三层各补各的盲，串联才闭环。TS 版已定案复刻（checkpointer 装饰器做信封 hash）。

LangChain/LangGraph 实现：checkpointer 装饰器——自写 class 包住真实 saver，put 时算指纹、getTuple 时验封；②b/②c 在验封通过后逐条过（普通 TS 循环内 await 微服务/判官 LLM）。

③工具分级表站 3 · 已定案

做什么：工具在网关注册时定级——低级（只读类：list/read 等）免签直用；高级（写/shell/出网等不可逆）必须人工授权后才生成短时令牌。

机制：分级表随网关工具目录下发，Agent 端每轮开局读取；等级是工具属性，不随任务变。注意：本站只是"读表"，授权动作发生在 ⑤（站 6）。

LangChain/LangGraph 实现：普通 TS——一张 Record<string, "low"|"high"> 常量（忽略）。

④LLM 调用站 4-5 · 已定案：经凭证代理

做什么：消息数组发模型，拿回复或工具调用意图。

用什么：LangChain.js ChatOpenAI，base_url 指向凭证代理（真 key 只活在代理进程，客户端只持占位符）。

机制：模型只产出 tool_calls 意图而非动作。"劫持了 Agent" ≠ "拿到了密钥"。

LangChain/LangGraph 实现：function calling 本体——ChatOpenAI 初始化只换 baseURL/apiKey 两个字段（凭证代理协议透明）；模型的 tool_calls 由 bindTools 注册的 schema 驱动。

⑤分级验票闸 + 短时令牌生成机制站 6 · 已定案（新设计）

做什么：模型的工具提议执行前过闸——低级工具直通；高级工具查票，无票则挂起。

触发（两条路）：a) 用户在输入框显式调用（如 @shell 运行 ls）；b) 模型提议高级工具 → 挂起 → 客户端向用户弹审批（展示工具名+完整参数）→ 用户确认。

签发：确认后由网关侧铸币（铸币权集中、可撤销；教学版可本地 HMAC 自签）生成一次性令牌：HS256，payload = { tool, args_hash, thread_id, nonce, exp=120s }。

绑定：工具名 + 完整参数哈希 + 会话——防"批了 A 执行 B"、防参数篡改。

验票：闸第零道 verify（签名 / exp / nonce 未消费 / 参数哈希一致），fail closed；用后即焚——nonce 消费记录，重放即拒。

机制：低级免签保可用性，高级人工授权保不可逆动作；替代原"每轮自动任务票"（0037）的自动推断。

LangChain/LangGraph 实现：闸 = createMiddleware 的 wrapToolCall（无票返回 ToolMessage "需人工授权"，不执行）；审批回路在主循环（普通 TS 三拍：闸拒→用户批→模型重试）；对照路径 interrupt() + Command(resume=) 留作学习。

⑥网关授权站 7 · 网关授权 agent 端工具使用

做什么：所有 Agent 端（×N）的工具调用只过这一扇门。

用什么：@modelcontextprotocol/sdk 的 Client + StreamableHTTPClientTransport，headers 带 Bearer 门票。

机制：三关按序——验门票（你是谁）→ 可见性/RBAC（你能看见什么）→ FGA 裁决（你能不能调，fail closed）。拓扑知识从客户端收走；收敛先于治理。裁决大脑是 OpenFGA——ContextForge 的 tool_pre_invoke 插件每次调用前去问它。

LangChain/LangGraph 实现：普通 TS——MCP client 调用（忽略）；注意授权裁决在网关侧，TS 端无代码。

⑦server 与执行面站 8-9

做什么：MCP server 出口策略（白名单/凭证策略）→ shell/fetch 在一次性 microVM 里执行。

用什么：现有 Python server + microsandbox 执行面原样沿用（与客户端语言无关）。

机制：独立内核 + 用完即焚 + 出网兜底——劫持得手的爆炸半径 = 一台即焚 VM。

⑧工具返回扫描站 10 · 间接注入主入口

做什么：工具结果回喂模型前查间接注入。

用什么：同一 llm-guard 微服务（分块扫描——稀释是分类器死穴）。

机制：有毒 → ToolMessage 换成警告消息回喂，模型知情但不接触毒原文。

LangChain/LangGraph 实现：wrapToolCall 中间件的回程半边——const result = await handler(request) 拿到返回值后先扫再放行；有毒则构造替换的 ToolMessage 返回。

⑨输出护栏站 11

做什么：回复展示前扫密钥/敏感数据——上游全失守也不让密钥出门。

用什么：llm-guard 微服务的 Sensitive 类扫描（NER+正则，实体白名单收窄防误报）。

LangChain/LangGraph 实现：wrapModelCall 中间件——包住模型调用，响应落图状态之前过扫描；命中则替换整条 AIMessage（脏内容也进不了记忆）。

⑩落库脱敏站 12

做什么：记忆写回前过 Presidio（Analyzer→Anonymizer）。

机制：消毒点选出口不选入口；已定案走微服务——与 llm-guard 同一模式（FastAPI 包 Presidio，HTTP 调用），可与护栏微服务同服务多端点。

LangChain/LangGraph 实现：checkpointer 装饰器的 put 半边——写盘前过消毒管道（同 ② 的装饰器，一读一写各管一段）。

◆ 审计伴随站 13

做什么：每站旁路出 trace——五要素（谁/何时/以何理由/什么参数/什么数据分级），被拦的也留痕。

用什么：Langfuse（观测）+ 哈希链（不可抵赖）沿用现有；TS 端经 SDK/HTTP 上报。令牌签发/挂起事件单独留痕（MINT 节点虚线入审计）。

LangChain/LangGraph 实现：callbacks——LangChain.js 的 CallbackHandler 传进 graph.invoke(input, { callbacks })，旁路观察不改行为；图外事件（拦截/签发）手动补录。

✅ 已定案（2026-09-03/04）

1. 凭证代理：保留——④ 经凭证代理，真 key 撤出客户端攻击面。

2. 本地闸：改造而非取消——0037 的"每轮自动任务票"升级为"工具分级 + 高级工具人工授权短令牌"（见 ⑤）；D4/法官可留作低级工具之外的纵深，按需裁。

3. 记忆装载校验：要做——TS 版用 checkpointer 装饰器复刻信封 hash（写入算指纹、读取验封）。

4. 多 Agent 端身份：门票 claims 区分——同一把铸币钥匙、票面印身份，网关验签后按 claims 裁决。

5. Presidio 路径：走微服务——与 llm-guard 同一模式（FastAPI 包库，HTTP 调用），可与护栏微服务同服务多端点。

6. 令牌签发方：教学版本地 HMAC 自签（0037 已有实现）；蓝图企业形态 = Keycloak/STS 铸币（token exchange）、ContextForge 验票——印钞厂拆给 STS，网关只当门卫。
