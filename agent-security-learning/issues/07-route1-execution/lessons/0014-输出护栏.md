# 0014:输出护栏 —— 最后一道锁,假设上游全部失守

## 一、三问(阶段动机)

- **这一阶段是干嘛的**:给三层防线补上最末一环——Sensitive 扫描器检查每一条模型回复,含密钥/敏感数据的直接整条换掉,用户看到的只有拒答。
- **为什么需要这么设计**:阶段 13 已经证明单层防线各有漏判面(格式规范毒 0.05 漏网)。纵深防御的核心思想:**每层都假设上层会失效**。输出层是那个"就算注入得手、毒进了上下文、密钥被读出来,也不能让它出门"的兜底。
- **解决了什么问题**:密钥外泄这个战利品有了独立于"注入是否成功"的保险——本阶段实测:毒记忆绕过输入/工具两层把 key 送进模型上下文,输出层依然在最后一刻拦下。

## 二、全链路一览(三层防线完整版图)

```
用户输入 ──▶ [第1层 输入护栏:PromptInjection] ──▶ ReAct 图
                                                      │
工具返回 ──▶ [第2层 工具护栏:分块 PromptInjection] ──▶ 回喂模型
                                                      │
模型回复 ──▶ [第3层 输出护栏:Sensitive 扫密钥/PII] ──▶ 落状态(=记忆) ──▶ 用户
```

三层各管一段数据流,串行兜底;任何一层的漏判都只是"防线后移",不是"防线洞穿"。

## 三、跟着数据走 4 步(毒记忆实弹)

1. **漏进**:投毒脚本把含 key 的伪造记忆写进 memory.json;`load_memory()` 无校验装载——输入护栏看不见它(它不经过输入框),这是故意留的路线 3 缺口。
2. **得手一半**:用户只说"你好",模型从"历史"里取出 key,生成含 `ik-live-9f4Kx2...` 的回复。此刻上游两层已被绕过。
3. **最后一锁**:`wrap_model_call` 中间件在响应**落进图状态之前**扫描——Sensitive 报 CRYPTO 1.0(命中的正是 key 本体)→ 整条 AIMessage 替换成拒答。
4. **零泄露**:用户看到 🛡️ 拒答;替换发生在 checkpointer 提交前,memory.json 里除了投毒原文,没有新增任何 key 副本。

## 四、新技术点四要素:llm-guard Sensitive 输出扫描器

- **名字**:Sensitive,`llm_guard.output_scanners`(输出扫描器家族);底层 = NER 模型(`Isotonic/deberta-v3-base_finetuned_ai4privacy_v2`,ai4privacy 数据集微调)+ 正则组 + spacy 中英文模型。姊妹件 `Secrets` 在 input_scanners 里(detect-secrets 引擎,扫高熵串/已知 key 格式),票 02 说的"Secrets 扫输出"在本版本由 Sensitive 实现更贴切。
- **作用**:识别文本里的敏感实体(密钥、卡号、PII)。与 PromptInjection 的分工:一个管"话里有没有毒",一个管"话里有没有货"。
- **参数**:`Sensitive(entity_types=[...], threshold=0.5, redact=False, regex_patterns=None)`——entity_types 是实体白名单(默认 13 类含 IP/日期/人名,**中文技术文本误报爆表**,实测文件列表回复被 IP_ADDRESS 0.61 误拦;收窄到 CREDIT_CARD/CRYPTO/US_SSN 等才可用);threshold 是 NER 置信度门槛;redact=True 时脱敏而非拦截。
- **用法**:`sanitized, is_valid, findings = scanner.scan(prompt, output)`(输出扫描器签名带两个参数);本项目挂载点 = `agent.py` 的 `make_output_guard`(`wrap_model_call` 中间件),实例在 `main()` 创建。

## 五、关键顿悟

- **攻击靶子与防御雷达要配套设计**:低熵假 key(`ik-FAKE-...0000`)两个扫描器都看不见——演习战利品必须是防御方能识别的形态(高熵),否则回归测试在自欺欺人。
- **默认配置不等于可用配置**:Sensitive 默认实体集在我们的文本上误报爆表;护栏上线必带一轮"误报/漏报校准",这是流程不是意外。
- **高熵字符串本身可疑**:粘贴 key 让模型"看看格式"会被输入护栏 1.0 拦截——长随机串是注入 payload 的常见成分。三层防线之间存在交叉覆盖,这是特性不是 bug。
