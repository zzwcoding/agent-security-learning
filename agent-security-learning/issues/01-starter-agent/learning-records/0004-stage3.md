# 0004: 阶段 3 —— filesystem MCP server 手动调通

**日期**:2026-08-27

**做了什么**:锁定 `mcp==1.29.1`(避开 2.0 API 变动);手写 `mcp_servers/filesystem_server.py`(read_file/write_file/list_dir,`_resolve` 防 `../` 逃逸);`agent.py` 加 `with_mcp()` + `/tools`、`/call` 调试命令。
