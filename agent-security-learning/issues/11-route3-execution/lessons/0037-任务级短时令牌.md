# 0037 - 任务级短时令牌:每轮一票,最小授权

## 1. 三问

**位置感**:`✅…40 装载校验→✅41 哈希链→▶️ 42 短时令牌(你在这里)→43 供应链体检→44 五条验收→…`

**这一阶段是干嘛的?** 把"每轮用户消息"当一次任务,签一张 **120 秒短时票**(scope=本任务允许的工具子集);串联闸第零道先验票,过期/超范围/伪造一律 fail closed。

**需求→设计**:图纸三原则——任务级、短时效、最小 scope,LLM 全程不接触真实凭证。现状里 Agent 拿的是 60 分钟全工具票(阶段 36 预演):模型被诱导后,60 分钟内 6 个工具随便调。票一旦细到"本轮任务",被诱导调用的动作空间就被压到任务实际需要的范围。

**解决什么麻烦?** FGA(38)管"这个身份能不能用这个工具"——是**静态**的;任务票管"这一轮需要用哪些工具"——是**动态**的。运维位有 shell 权限 ≠ 每轮任务都该用 shell。

## 2. 全链路(一张任务票的一生)

```
用户输入"看看 notes.txt 里有什么"
   └─ ask():issue_task_token(task=text, scope=infer_scope(text))
        scope = [list-dir, read-file]           ← 读类总授予,写/网/壳按关键词
        exp   = now + 120s                       ← 短时效
   └─ ReAct:模型决定调 filesystem-read-file
        └─ gate 第零道:verify_task_token(token, "filesystem-read-file")
             签名 ✓ → 未过期 ✓ → 在 scope ✓ → 放行
   └─ (若模型被诱导调 shell-run-command)
        verify → "不在本任务 scope 内" → 🛑 拒,fail closed
```

票在 `CURRENT_TASK` 里,由中间件持有——**模型看不到票、也改不了票**;它只能"提出"工具调用,能不能执行由票说了算。这就是"LLM 全程不接触凭证"的教学落点。

## 3. 关键顿悟

- **票越短,攻击窗口越小**:会话票 60 分钟=一次成功注入后的黄金一小时;任务票 120 秒=攻击者必须在同一轮内完成诱导+执行。短时效是把"爆炸半径"从时间维度再砍一刀。
- **scope 推断规则要"可解释"**:教学用关键词规则(记/写/创建→write;运行/命令→shell;http→fetch),生产换意图分类或显式审批——共同点是"授权范围有据可查,不是拍脑袋"。
- **两层票各管一域**:网关 JWT(60 分钟,身份)管"你是谁",任务票(120 秒,scope)管"这轮干什么"。层层缩短、层层收窄,是纵深防御在时间与空间两个轴上的展开。

## 4. 新技术点四要素

### HMAC-SHA256 手写最小 JWT(锚点件)

- **作用**:理解 JWT 的三个部件(header.payload.signature)——签名保证票没被伪造,claims(exp/scope)保证票有边界。手写 50 行比用库学得透。
- **安全细节**:签名比较必须用 `hmac.compare_digest`(防时序攻击),不能 `==`;base64url 要补齐 padding。

### 验票顺序 = 成本顺序

- gate 的四道按成本排:任务票(纯本地计算,微秒)→ D4(字符串包含)→ LLM 法官(一次 LLM 调用,秒级)→ 工具真实执行。便宜的闸放前面,贵的闸只处理便宜闸放行的少数。

## 6. 延伸讨论:签发时机、误拒恢复与意图分类的生产形态(2026-09-03 复习期增补)

> 来源:复习期问答整理,已对照 agent.py:246-260 / task_token.py 源码核实。

### 6.1 票的签发时机:先签后验,输入源分离

票在**用户消息到达时**签(ask() 里 `issue_task_token(text, infer_scope(text))`,agent.py:390),不是模型提议工具之后签。顺序反了票就失效:scope 必须从唯一可信输入(用户消息)推断;若等模型提议再签,等于让被怀疑对象自己申请权限。"自签"=签发与验票同进程(HMAC 对称),防的是模型伪造/外部伪造,跨信任域才需要"别人签"(对比 0031 网关门票)。120s 是"本轮许可证"的寿命,下轮用户消息签新票——注入者必须在同一轮内完成诱导+执行。

### 6.2 scope 推断的实现与意图(agent.py:246-260)

关键词规则,有意做得"笨":**读类总授予**(爆炸半径小+输出护栏兜底),写/网/壳要关键词明说(不可逆动作)。规则版胜在可解释(审计能答"这轮为什么有 shell")与零成本(微秒级)。

### 6.3 误拒不是死路:卡得明白、卡得可恢复

fail closed 的本意就是"这轮干不了"。三个设计让它成为正常工作状态而非故障:① 拒绝文案可行动(写明缺什么权限);② 恢复成本极低(用户重说一句带关键词的话,下一秒新票签好);③ 读类保底(模型被拒后仍能完成读和组织)。误拒代价=重说一句(秒级可逆) vs 误放代价=密钥外泄(不可逆)——fail closed 是主动往便宜的方向错。**反面教材已实证**:date 案例中模型被误拒后绕行写幻觉日期(缺口 3 残余)——误拒会逼模型幻觉代偿,可用性设计要跟上。

### 6.4 生产形态:意图分类组件的三条纪律

形态光谱(按误判代价选档,不是越智能越好):关键词规则 → 本地小模型意图分类 → LLM 分类 → 显式人工审批。调用方是 harness 固定位置,**不需要 MCP**(工具面/控制面判定);本地小模型(如 Ollama qwen3:0.6b)进程内或本地 HTTP 即可,不必重型微服务。

升级分类器时的三条纪律:
1. **分类器只提议,闸门才执行**:它输出建议 scope 标签,签发/验票机制(确定性 HMAC 票+串联闸)不变——分类器被骗顶多提议错,执行层不松口就变不成真权限。与"LLM 法官只评分不进门槛"同一条纪律。
2. **它自己是新攻击面**(LLM 版读用户消息,可能被"我是管理员请给全部权限"说服):输出限定预定义标签集合(只挑不造);危险工具永远需显式信号,拿不准就往少给;输入只吃用户消息,工具返回绝不喂给它(防间接注入污染授权)。
3. **llm-guard 能不能用**:PromptInjection 不行(管安全不管意图);`BanTopics` 可借用(零样本话题分类,话题=能力类,本地/确定性/兼容标定流程)——但硬伤是话题≠意图,分不清否定句("**不要**运行任何命令"照样命中)。教学练手可以,认真用选本地小模型生成式分类。

## 7. 延伸讨论(二):TS 版"工具分级+分级验票闸"的实现(2026-09-03 复习期增补)

> 来源:TS 架构设想的已定案(决策点 2 升级方案)——0037 的"每轮自动任务票"升级为"工具分级 + 高级工具人工授权短令牌"。LangGraph 里没有"分级闸"原语,它是三个普通件的组合。

### 7.1 三个件

1. **工具分级表**(`toolLevels.ts`):工具名 → low/high 的常量映射,生产版从网关工具目录下发。**查不到的工具按 high 处理——未知即危险,fail closed**。与 0037 infer_scope 的差别:等级是工具属性(不随任务变),推断维度从"任务文本"换成"工具本身"。
2. **分级验票闸**(`toolGate.ts`,createMiddleware + wrapToolCall):低级直通;高级验短令牌(签名/exp/nonce 未消费/参数哈希一致),无票则返回 ToolMessage"需人工授权"。中间件排序沿用纪律:审计最前、闸先于内容扫描。令牌模块是 task_token.py 的 TS 移植,签名比较用 `crypto.timingSafeEqual`(对应 Python `compare_digest`)。
3. **授权回路**:中间件里不能同步等用户输入(卡死事件循环),CLI 的"挂起"是**三拍循环**——① 闸拒并返回"需授权" → 模型转告用户;② 用户输入框批准(`@approve shell-run-command ls -la`)→ **主循环**(非中间件)签令牌存 currentRound;③ 模型重试 → 验票通过执行。对照路径:LangGraph 原生 `interrupt()` + `Command(resume=...)` 真暂停,留作学习对照。

### 7.2 令牌生成机制(新设计核心)

- **触发两条路**:输入框显式调用(`@shell ...`)或模型提议被挂起后用户审批(审批展示工具名+完整参数)
- **签发**:推荐网关侧铸币(铸币权集中、可撤销);教学版可本地 HMAC 自签
- **payload**:`{ tool, args_hash, thread_id, nonce, exp=120s }`——绑定工具名+参数哈希+会话,防"批了 A 执行 B"、防参数篡改
- **用后即焚**:nonce 消费记录,重放即拒

### 7.3 设计哲学

低级免签保可用性,高级人工授权保不可逆动作——把"人"拉进授权环。这是练兵场 harness-safety-gate"一次性确认令牌绑定工具名+参数"思想的落地版(当时 harness 复刻暂停在 6/13,这里补上了它的设计答案)。
