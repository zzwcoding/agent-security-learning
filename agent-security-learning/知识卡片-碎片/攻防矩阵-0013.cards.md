# 攻防矩阵 0013 收官对照 —— 知识卡片

来源:`攻防矩阵复刻/lessons/0013-收官对照.md`

### 三防线逐维对照法(Three-Defense-Route Comparison)

- **是什么**:把三条防御路线——D2/D3 提示词层(本实验)、starter-agent 三层外部分类器(llm-guard 输入/工具返回/输出扫描)、D4 执行层——拉到同一张表上,按六个维度逐维对照:判定依据(模型自觉 / deberta 分类分数+NER 正则 / 字符串事实)、性质(概率 / 概率 / **确定性**)、成本(零 / 每条内容过一次分类器 / 零)、对记忆注入的表现、失败模式、可观测性。
- **为什么重要**:对照出的核心结论——**两条上下文路线是同一种"概率性"的两个变种**:提示词层赌"模型愿意听话",分类器赌"分类器认得出注入形状";分类器也是模型,只是不生成文本。两者都降概率,都不兜底(本实验 D3 翻车 0%↔100% 与精读笔记扫描器对毒偏好判 -1.0,分别从两条路线实证)。
- **我们怎么用**:评估任何新防线先做定性(概率/机制)再比数字;给一层防御定性时问"它赌什么"——赌模型听话、赌分类器认得出,还是赌代码里的字符串事实。

### 盲区互补:内容 vs 动作(Complementary Blind Spots / Content vs Action)

- **是什么**:两条路线的失败模式恰好错开——分类器判"这段文本像不像注入",它**不知道用户本轮授权了什么**,所以对良性外衣的越权(记忆注入:毒是无害偏好文本)天然失明;D4 判"这个动作是否越权"(目标∈本轮用户消息),它**不看文本像不像注入**,所以对措辞免疫。前者管内容,后者管动作。各自的失败模式:提示词层怕模型不听劝,分类器怕对抗样本/分布外 payload/阈值误杀,执行层怕政策本身设计错(如"语义授权"匹配不到)。
- **解决什么问题**:回答"该选哪条路线"——答案是叠加而非二选一:**完备配方 = 分类器降噪声(挡脚本小子)→ 提示词层降概率(抬攻击成本)→ 执行层兜底(钉死最坏情况)**。starter-agent 缺第三层,本实验缺第一层,缺口恰好互见。
- **我们的办法**:收官结论给出具体的互补方向——把 llm-guard 扫描器接到本实验 `execute_tool` 入口之前,把 D4 移植进 starter-agent 的中间件链,两边缺口就都补上。

### 复刻差级 diff 对照法(Strip-Diff Triage)

- **是什么**:复刻项目收官时的对照方法——strip 掉注释做功能级对比(而非逐行 diff),然后把差异分三级记账:**完全复刻**(逐字/语义相同,如三攻击 payload、判定器、D4 政策、路径收敛、outbox 隔离)、**有意的改进**(以我们为准的偏离,须带理由,如每轮重建系统提示词让记忆通道承重、Keychain 替代 .env、30 行裸客户端替代 provider 注册表)、**真正的差距**(没复刻的欠债,如实列出:CLI、错误处理/timeout、工作区隔离粒度 mkdtemp vs 固定目录、正式跑批 N=4 未做)。
- **为什么重要**:逐行 diff 会被注释和风格差异淹没;三分法逼你对每一处偏离表态——是"同样"、是"有意改"还是"欠债",防止复刻项目在沉默中漂移,也让"改进"必须携带理由才能成立。
- **我们怎么用**:任何复刻/移植类任务收官时按这三栏出对照表;"有意的改进"栏每条必须写得出理由,写不出理由的偏离归入"真正的差距"。

### 三层防线的市场选型地图(Defense Layer Landscape)

- **是什么**:上下文层与执行层的现成选项速览。注入分类器:llm-guard(本项目用)/ Lakera Guard / Azure Prompt Shields / NeMo Guardrails——都是概率性内容过滤,差异在模型大小、延迟、阈值可调性;提示词层:手写加固+来源标记(本实验)/ Spotlighting(微软,定界符+编码)/ StruQ(指令数据分离训练)——从"劝"到"改训练",概率逐级降但非零;执行层:一句话白名单(本实验)/ 结构化审批流(人工二次确认)/ 能力凭证(capability token,授权随凭证下发)——确定性,**是唯一能写进 SLA 的层**。
- **解决什么问题**:给"防御选型"提供坐标系——同一层内的产品可以互换(都是概率性,比谁噪声低),跨层不能替代(分类器再好也不兜底)。
- **我们的办法**:选型口诀一句话收官——**内容层任你选,执行层不能省**。
