### OpenAI 兼容端点(OpenAI-Compatible Endpoint)

**是什么**:一个事实标准——只要模型供应商提供 OpenAI 兼容端点(`base_url` + `Bearer` key),同一份 `openai` Python 客户端代码换三个环境变量(`LLM_API_KEY`/`LLM_BASE_URL`/`LLM_MODEL`)就能换模型,不换代码。核心调用是 `chat.completions.create(model, messages, [tools], ...)`,messages 是 `{"role": system/user/assistant/tool, "content"}` 列表。
**解决什么问题**:复刻类实验的供应商替换问题。参考项目用 `agentbook.providers` 注册表接 gpt-4o-mini,我们 30 行裸客户端走 `api.minimaxi.com/v1` 接 MiniMax-M2——兼容协议把"换模型"从改代码降为改环境变量。
**我们的办法**:`demo.py:29-41` 裸 `OpenAI(api_key, base_url)` 客户端;key 从 macOS Keychain 经 `agent-key` 只注入子进程环境,不落盘——密钥不写 `.env` 本身也是防注入泄露的第一课。
