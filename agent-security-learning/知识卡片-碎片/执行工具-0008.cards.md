# 执行工具 0008 长输出截断与落盘 —— 知识卡片

来源:`执行工具复刻/lessons/0008-长输出截断与落盘.md`

### 留头尾的输出截断(truncate_and_persist Head-Tail Truncation)

**是什么**:工具输出超阈值(>200 行或 >10000 字符)时,进上下文的只留头 50 行 + 省略说明 + 尾 50 行;全文一字不丢写进临时文件,路径随结果返回(`stdout_file` 字段)。没超就原样返回,`stdout_file = null`。
**解决什么问题**:输出迟早喂回 AI,一条 `find /` 几十万行能一次撑爆上下文。留头尾而非只留头,是因为**报错和结论几乎总在最后几行**(traceback 在尾),开头交代前奏,中间最没信息量。顺带沾一条安全边:工具输出是不可信内容,截断缩小了注入暴露面——但这道工序本质是"别把自己玩死"的生存工程,不是安全闸。
**我们的办法**:规则(数行数)就够,零成本零延迟,不用请 AI。实跑 1000 行输出 → 上下文里 100 行 + 一个文件路径,落盘文件验证一行没少。

### 上下文里放指针,不放大文件(Pointer, Not Payload)

**是什么**:截断不等于丢数据——全文落盘 + 返回路径,AI 看完头尾还想看中间,用 `read_file` 按路径自己去读。agent 工程常用手法。
**为什么重要**:上下文窗口又贵又有限,是稀缺资源;把大对象换成指针,AI 按需取阅,既保信息可达又保窗口不爆。
**我们怎么用**:结果 JSON 拆成两段:`stdout` 是瘦身后的精华,`stdout_file` 是全文路径;对照组短输出原样返回、路径为 null——没超不折腾。

### tempfile.mkstemp 安全临时文件(tempfile.mkstemp)

**是什么**:Python 标准库,在系统临时目录创建**名字保证不重复、别人打不开**的文件,返回 (文件句柄, 路径);比自己拼文件名安全——不会撞名、不会被抢注攻击。`prefix=`/`suffix=` 只起辨识度作用。
**解决什么问题**:落盘全文需要写临时文件,手写文件名有撞名和符号链接抢注(temporary file race)风险;mkstemp 原子创建,从机制上免掉这类竞态。
**我们的办法**:`execution_tools.py:30`,拿到句柄后用 `os.fdopen(fd, "w")` 包成普通文件对象来写。注意定位:系统临时目录重启会被清理,是"本次干活的草稿纸",不是存档。
