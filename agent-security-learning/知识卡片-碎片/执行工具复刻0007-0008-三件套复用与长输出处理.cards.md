# 执行工具复刻0007-0008 三件套复用与长输出处理 —— 知识卡片

### list-form subprocess(参数列表形式)

是什么:列表形式指用 subprocess(Python 标准库里负责拉起子进程的模块)启动程序时,把程序路径和每个参数逐项放进一个数组,交给操作系统去启动。它不把整段命令文本交给 shell(命令行解释器)解析,这是与 `shell=True` 写法的对照面:`shell=True` 时整段文本会被 shell 完整解析,分号、`&&`、输出重定向这类特殊符号全部生效。

解决什么问题:命令文本一旦经 shell 解析,混在文本里的 shell 语法就会被当真执行,"借 shell 之手干活"正是命令注入的经典通道。列表形式下,那段文本只是目标程序的一个普通参数,里面的 shell 语法不再被解释——这条通道被结构性封掉,而不是靠检查去堵。

我们的办法:代码执行工具把 AI 提交的 Python 代码装进 `[当前解释器路径, "-c", 代码文本]` 这样的列表去起子进程,列表第一项用当前解释器的路径来保证跑代码和跑工具是同一个 Python 环境。实测藏了 `os.system('echo pwned-by-code')` 的提交在更前面的清单检查就被拦下,而列表形式还保证代码里写满分号与管道也只是参数里的普通字符,轮不到外层 shell 解释。

### language-scoped danger patterns(按语种分组的危险模式清单)

是什么:按语种分组,指危险模式清单(枚举已知危险片段、命中即拦的清单式防御)按输入代码的语言各维护一张——shell 一张、Python 一张,而不是所有工具共用一张大表。

为什么重要:不同语言"开门作恶"的口子不一样。shell 的破坏走命令本身,要防 `rm -rf`(递归强删)这类片段;Python 的破坏常是借标准库开洞,一条 `os.system`(在代码里执行 shell 命令)就能把一整个 shell 藏进代码,所以要防 `os.system` / `eval` / `exec`。共用一张表则两头都防不全。这也反向证明"语法检查 → 清单筛子 → 大模型审批"这条流水线不是 shell 专用:接入新工具只需换掉筛子的那张清单,整条流水线原样复用。

我们怎么用:给跑代码工具配防线时,检查的位置与分工照旧,只换 Python 版模式表。实测 `os.system('echo pwned-by-code')` 命中清单后送审批(第二个大模型执行前裁决放行与否),拒绝理由点破动机:"pwned 这词看着就像在试探防线"。无害的 `open('hello.txt').read()` 因 `open(` 在表上被误送审,又按"只读 / 不联网 / 无副作用"放行——清单的粗糙是故意的,职责只是"喊审批员来看"。

### truncate-and-persist(长输出截断与全量落盘)

是什么:这是一套给执行工具输出"瘦身"的双轨返回机制:喂回 AI 的结果里只保留输出的头尾片段,全文一字不落写进临时文件,再把文件路径附在结果里一起返回。留尾和留头同样重要是刻意设计——报错现场(如 traceback,程序崩溃时打印的调用栈)几乎总在最后几行,开头交代"跑的是什么",中间通常最没信息量。

解决什么问题:执行输出迟早要喂回 AI,而 AI 的上下文窗口(模型单次能读到的全部内容的容量上限)又贵又有限;一条 `find /` 能打出几十万行,全塞进去一次就撑爆上下文,后面的对话没法进行。安全上还有一笔附带收益:工具输出属于喂回 AI 的不可信内容(可能藏注入指令),截断顺带缩小了注入的暴露面。

我们的办法:判断用"数行数、数字符"的机械规则,不劳驾任何模型:不超过 200 行且不超过 10000 字符就原样返回,超了才落盘并拼成"头 50 行 + 带路径的省略说明 + 尾 50 行"。实测 1000 行输出返回了 100 行精华加一个路径,临时文件里一行不少,AI 想深挖就拿路径自己去读——这正是"上下文里放指针、不放大文件"的 agent 工程惯用招。

### tempfile.mkstemp(安全临时文件创建)

是什么:tempfile.mkstemp 是 Python 标准库里创建临时文件的函数:在系统临时目录造出一个"名字保证不重复、别的用户打不开"的文件,返回文件句柄(操作系统发的读写通行证)和路径。文件名中段那串乱码(如 `code_interpreter_output_m0c8mb8q.txt` 里的 `m0c8mb8q`)就是它生成的唯一部分。

解决什么问题:自己拼临时文件名(固定名或加时间戳)有两个经典坑。一是撞名:两个进程同时写同一个文件,互相覆盖。二是抢注:攻击者猜到你的临时文件路径,预先在那里放一个符号链接(指向另一路径的文件替身),你的写入就落到它指定的目标上。mkstemp 的唯一性保证加默认收紧的权限,把两类风险一并消掉。

我们的办法:输出落盘前先调它拿句柄和路径,再用 `os.fdopen`(把句柄包成普通文件对象的函数)写内容,prefix/suffix 参数给文件名加辨识度。要记住它的定位是"本次干活的草稿纸":系统临时目录重启会被清理,不能当存档用。
