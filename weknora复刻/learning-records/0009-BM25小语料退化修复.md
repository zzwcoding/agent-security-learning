# 0009 · BM25 小语料退化修复（用户实测驱动）

- 日期：2026-09-10
- 现象（用户页面实测）：库里只传 1 份 cat.txt 后，①BM25 任何查询零命中；②向量路任何查询都返回那张 cat 卡片。
- 诊断：①书原 IDF 公式在 df≥N/2 时取负（小语料必中），"下限 0 截断"把整路归零；②向量路无"零命中"概念（余弦永远有第一名）——不是 bug，是两路检索的性格差异。
- 修复：IDF 换工程变体 ln(1+(N−df+0.5)/(df+0.5))（Lucene/ES 同款，恒非负、排序性质不变）；手算对照测试数值同步更新（ln3→ln4、ln1.4→ln2.4）；新增回归 `test_bm25_tiny_corpus_still_hits`。22 测试绿。
- 教学增量：lessons/0002-1"捣乱观察"改写为本次翻车实录（书给原理、工程填坑）；lessons/0003-3 增"向量检索没有零命中"顿悟。
- 结论：现象①是 bug 已修；现象②是本性，靠丰富语料（≥2-3 份不同文档）显形差异。
