# ADR 0001 · 架构图 v1 过审

- 日期：2026-09-10
- 结论：架构图 v1（`docs/architecture-v1.md`）与 8 张模块卡（`specs/modules.md`）经用户过审，5 个过审决策点全部按推荐落锤。过审后任何编码以此为准。
- 过审决策点（用户原话"按你推荐的"）：
  1. 8 模块划分：两叶子（`store`/`llm_gateway`）+ 三管线（`retrieval`/`graph`/`wiki`）+ 两编排（`ingest`/`qa`）+ 表现层（`webui`）
  2. 索引投影写入面归 `retrieval`（`ingest` 只做四开关分发，不知索引细节）
  3. 共享 dataclass 由 `store` 导出，不立独立 types 模块
  4. `SearchTrace` 中间态进 `retrieval` 公开接口（问答页对比视图的正式查询面）
  5. `webui` 可只读直连 `store`（列表类查询），写操作一律走管线模块
- 用户提出的修改：安全防线接入椒图 M3——单独立 ADR 0002 处理（变更路由）。
- 遗留问题：无。
- 机检状态（过审当场）：spec gate PASS（8 条"目录未建"WARN 为规划合法）；boundary gate PASS（8 模块卡已声明）。
