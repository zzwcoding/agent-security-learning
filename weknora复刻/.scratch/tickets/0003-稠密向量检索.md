## 范围

- `llm_gateway` 首次落地：`chat`（签名先落，本票不消费）+ `embed` + `backend_name` + `use_fake_backend`；真实 GLM 后端（httpx，key 经 `agent-key glm` 从 Keychain 取）+ fake stub 确定性后端；**配置面：base_url / api_key / 模型名走环境变量，base_url 默认智谱端点，请求结构 OpenAI 兼容**（ADR 0002）

- `webui`：查询框加"检索路"切换（BM25 / 向量），页面标注 `backend_name()` 当前是真 API 还是 stub
- 书锚点：3.2 稠密嵌入；WeKnora 锚点：`processChunks` 中 embedding 写入 `knowledge_process.go:283`

## 边界红线

- 允许触碰：`llm_gateway/`、`store/`、`retrieval/`、`webui/`、`tests/`、requirements.txt
- import 范围：`retrieval` 只许 import `store`、`llm_gateway`；`llm_gateway`/`store` 不许 import 任何业务模块（叶子，边界规则第 5 条）
