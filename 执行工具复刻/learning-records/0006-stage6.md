# 0006 — 阶段 6:二级 LLM 事前审批

## 学了什么

- `llm_helper.py` 新增 `request_approval` + `_ensure_client`(懒创建)+ `_parse_json`(剥围栏容错)
- `virtual_terminal`:黑名单命中 → 送审批,批了才执行;结果 dict 新增 `approval` 字段
  (not_required / passed:理由 / denied)
- fail-closed 实锤:无 key 时审批按拒绝处理——demo 离线能跑的根因
- 复用 config.py 的 LLM_* 三件套;openai 包已由 langchain-openai 带入,零新增依赖

## 验证(实跑四案)

- 无 key + `rm -rf /tmp/xxx` → denied("无法审批")✅ fail-closed
- 有 key + `echo 注意:rm -rf...` → **批准并执行**,法官看穿字面文本 ✅ 误伤救回
- 有 key + `rm -rf /tmp/exec_demo_nonexistent_xyz` → **批准**(理由:范围限 /tmp、像测试)
  —— 法官心慈的实例,写进 lesson 顿悟 3
- 有 key + `mkfs.ext4 /dev/sda1` → **拒绝**,理由清晰 ✅(选 mkfs 做拒案:macOS 无此命令,
  就算误判批准也无实际破坏——危险演示的安全选例)
