# 阶段 8:长输出截断 + 落盘(truncate_and_persist)

## 一、三问(阶段动机)

**你在整盘棋的哪一步**(终极目标:给 AI 助手用的工具,每个进门先安检):

```
✅ 阶段 2-3   写文件工具:边界 + 语法两道闸
✅ 阶段 4-6   跑命令工具:能跑 + 筛子 + 法官
✅ 阶段 7     跑代码工具:三件套复用
👉 阶段 8     长输出瘦身:输出太长时留头尾、全文落盘——本阶段
⬜ 阶段 9     文件编辑 + 覆盖审批
⬜ 阶段 10-12 demo 串烧;换回 agent 身上做攻击前后对比
```

**这一阶段是干嘛的**:给两个执行工具的输出装"瘦身器"——命令打出 1000 行时,
结果里只留头 50 行 + 尾 50 行,完整内容存进临时文件,文件路径随结果返回。

**先坦白:这道工序严格讲不是安全闸,是"别把自己玩死"的生存工程**
(用户读到这时就问了"这和安全有啥关系"——感觉是对的)。它在安全主线之外,
只有一条边沾安全:工具输出是喂回 AI 上下文的不可信内容,可能藏注入指令,
截断缩小了注入暴露面。真正的安全主线在闸上(阶段 2-3/5-7/9),
阶段 11 的攻击前后对比会让"安全"显形——现在是造防弹衣,还没挨子弹。

**为什么需要**:这些输出迟早要喂回给 AI(它的上下文窗口又贵又有限)。
一条 `find /` 能打出几十万行,全塞给 AI,一次就把上下文撑爆——
后面的对话全没法进行了。

**解决了什么问题**:AI 既能看到输出的"精华"(头尾),又拿得到全文(文件路径),
上下文还不爆。实跑:1000 行输出 → 结果里 100 行 + 一个文件路径。

## 二、全链路一览

```
工具执行完,拿到 r.stdout(可能几十万行)
  → truncate_and_persist()
       ├─ ≤200 行且 ≤10000 字符 → 原样返回,stdout_file = null
       └─ 超了 → ① 全文一字不丢写进临时文件
                 ② 拼"头 50 行 + 省略说明(带文件路径) + 尾 50 行"
  → 结果 JSON:stdout 是瘦身的,stdout_file 是全文路径
  → (将来的)AI 看完头尾还想看中间?它有 read_file,自己按路径去读
```

## 三、跟着数据走 3 步(实跑:打印 1000 行)

1. **产出**:`for i in range(1000): print(...)` → stdout 是 1000 行文本。
2. **瘦身**:超了 200 行 → 全文写进
   `/var/.../code_interpreter_output_m0c8mb8q.txt`(**实跑验证过:文件里 1000 行,一行没少**);
   返回文本 = 第 0~49 行 + `... [省略 900 行,完整输出已保存至 ...] ...` + 第 950~999 行。
3. **消费**:AI 拿到 100 行精华 + 路径,想深挖随时 read_file。
   对照组:短输出 `print('short')` 原样返回,`stdout_file` 是 null——没超不折腾。

## 四、新技术点:tempfile.mkstemp

- **名字**:`tempfile.mkstemp`,Python 标准库 tempfile 模块
- **作用**:在系统临时目录创建一个**名字保证不重复、别人打不开**的文件,
  返回 (文件句柄, 路径)。比自己拼文件名安全:不会有撞名、不会有抢注攻击。
- **参数**:`prefix=`/`suffix=` 只是给文件名带点辨识度
  (`code_interpreter_output_m0c8mb8q.txt` 里那串乱码是它生成的唯一部分)。
- **用法**(本项目 `execution_tools.py:30`):拿到句柄后用 `os.fdopen(fd, "w")`
  包成普通文件对象来写。
- 注意:系统临时目录重启会被清理——它定位是"本次干活的草稿纸",不是存档。

## 五、关键顿悟

- **为什么留头尾,不是只留头**:报错信息和最终结论几乎总在**最后几行**
  (traceback 在尾);开头交代"跑的是什么、前奏是什么"。中间部分通常最没信息量。
  只留头 = 把最重要的错误现场扔了。
- **截断不等于丢数据**:全文落盘 + 返回路径,AI 需要细节可以自己去读——
  "上下文里放指针,不放大文件",这是 agent 工程里很常用的一招。
- **瘦身不需要 AI**:规则(数行数)就够,零成本零延迟。这再次印证阶段 6 的分工:
  有标准答案的事别麻烦法官。(参考项目还留了后手:头尾都超 1 万字符再请 LLM 总结,
  我们按交接文档砍掉了,知道有这回事即可。)
